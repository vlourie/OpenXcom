# Вступление: фотографии и голос

Вместо неподвижной картинки `Intro_00.png` — показ кадров под твой голос. Движок показывает
слайды сам (катсцена `intro`), поэтому видеокодек не нужен: каждый слайд висит ровно столько,
сколько длится его озвучка.

## Порядок работы

### 1. Сценарий

```powershell
python tools\intro\make_script.py
```

Читает `options.cfg` установки Пираток, проходит активные моды в порядке загрузки и берёт ту
катсцену `intro`, которую игрок **видит** (русский патч объявляет свою заново). Пишет два файла:

| Файл | Кому |
|---|---|
| `docs/intro-script.md` | тебе: номер, кадр, текст, оценка секунд на чтение |
| `tools/intro/scenes.json` | сборщику |

Сейчас это 16 сцен, примерно 5:53 озвучки.

### 2. Твои материалы

```
E:\intro\
    photo\01.png … 16.png    номер = номер строки в таблице
    voice\01.wav … 16.wav    голос на эту сцену (wav, mp3, ogg — всё равно)
    music.ogg                подложка, необязательно
```

Картинки — любого размера, соотношение 4:2.5 (1280×800, 2560×1600). Другое соотношение будет
обрезано по центру. Порядок и содержание сцен — из таблицы сценария.

Номер сверяется числом, а не строкой: `1.png`, `01.png` и `1 - причал.png` — одна и та же
сцена. Сцена без файла голоса держится 4 секунды.

### 3. Сборка

```powershell
python tools\intro\build_intro.py --in E:\intro --mod user\mods\hd
```

Что делает:

* длительность слайда = длина файла голоса + пауза (`--pause`, по умолчанию 1,2 с);
* `Resources/Intro/intro_NN.png` — кадр 320×200 с собственной палитрой для классического слоя;
* `hd/UI/intro_NN.png` — тот же кадр в 4× для HD-слоя; HD-слой находит его по содержимому
  базовой картинки, поэтому оба обязаны быть одним и тем же снимком;
* `SOUND/intro_voice.ogg` — весь голос одной дорожкой, каждая реплика на своей секунде,
  музыка под ним тише на `--music-db`;
* `Ruleset/intro.rul` — `delete: intro` и своя катсцена.

Полезные ключи: `--dry` (только посчитать длительности), `--no-captions` (без подписей),
`--scale` (кратность HD-кадра), `--scenes` (свой список сцен).

### 4. Проверка

```powershell
python tools\intro\build_intro.py --in E:\intro --mod <тестовый мод> ; # и запустить игру
```

В `openxcom.log` смотреть три строки:

* `HD interface: N HD picture(s)` — N должно вырасти на число сцен;
* `HD picture: hd/UI/intro_NN.png` — появляется, когда слайд реально показан HD-слоем;
* `is far from` — **не должно быть**: значит HD-кадр не признали снимком базовой картинки.

## Грабли, на которые уже наступили

**Громкость музыки.** У катсцены нет отдельного канала для озвучки — только `musicId`. Значит
голос для игры это МУЗЫКА, и при `musicVolume: 0` в `options.cfg` вступление идёт в полной
тишине: дорожка найдена, запущена и заглушена ползунком. В логе об этом ни строки (R-032).

**Палитра.** Индексы 1…239 — цвета снимка, 241…245 — лесенка для подписи, индекс 0 движок
считает прозрачным и снимком не занят. Поэтому `captionColor: 240`: буквы рисуются в
`цвет+1 … цвет+5`.

**`_CPAL` в имени спрайта.** Без него `Mod::loadExtraSprite` кладёт на картинку палитру
состояния, и HD-снимок сверяется с чужими цветами.

**`delete: intro` обязателен.** `RuleVideo::load` слайды не заменяет, а дописывает: без
удаления к твоим 16 кадрам приклеятся 16 чужих.

**Порядок модов.** Катсцену получает тот мод, который грузится последним. В установке Пираток
`hd` стоит после `XPZ_EX_RU-patch` — это и нужно.

**Длительность слайда.** Движок показывал слайд вдвое дольше заказанного; починено в
`src/Menu/SlideshowState.cpp` (см. `docs/RAKES.md`, R-029). На старом бинарнике тайминг голоса
разъедется — собери игру заново.
