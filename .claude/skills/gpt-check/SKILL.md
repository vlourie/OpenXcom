Что проверить: **$ARGUMENTS**

**Только с явного разрешения Vitali на этот запуск** (DECISIONS 2026-10-05, CLAUDE.md п.10). Разрешения нет — не запускать, спросить.

Codex здесь — проверяющий, только чтение. Правишь ты. Его правила лежат в `AGENTS.md`.

## 1. Выбери режим

| Что проверяем | Команда |
|---|---|
| незакоммиченные правки этой сессии | `py -3 tools/gpt_check.py diff <свои файлы>` |
| коммит | `py -3 tools/gpt_check.py commit <sha>` |
| файл как есть | `py -3 tools/gpt_check.py file <путь>` |
| ответ, план, вывод исследования | запиши текст в файл блокнота → `py -3 tools/gpt_check.py text <файл>` |

Аргументов нет — бери `diff` по файлам, которые правил в этой сессии. Пути в `diff` обязательны:
в дереве работают несколько сессий, чужие правки на проверку не отдавать.

`--ask "..."` — на что смотреть в первую очередь. Пиши туда **утверждение, которое надо опровергнуть**
(«без флага поведение прежнее», «режим 0 не затронут»), а не свой вывод о том, что всё верно.
Свои догадки о причине не подсказывай — проверяющий, которому дали гипотезу, её подтверждает.

Глубина — как в настройках Codex у Vitali (`xhigh`, 10–30 минут на коммит). Для мелочи — `--effort medium`.

## 2. Запусти в фоне и дождись файла

Запуск долгий — `run_in_background`. Результат: `.gptcheck/<время>-<режим>.md`, в шапке номер беседы.
Ответа нет — смотри `.log` рядом, не перезапускай вслепую.

## 3. Проверь каждое замечание сам

Замечание Codex — это гипотеза, а не факт, и не шум. По каждому открой названные строки и реши:

- **подтверждено** — ошибка есть, сценарий воспроизводится по коду;
- **не подтверждено** — покажи строку, которая это опровергает;
- **спорно** — по коду не решается, нужен запуск (назови какой).

Не соглашайся из вежливости и не отмахивайся: у второго проверяющего те же слабости, что у тебя —
он может сослаться на строку, которой нет, или не знать решения из `docs/DECISIONS.md`.

Есть «не подтверждено» по существенному пункту — один круг возражений:
запиши ответ в файл и `py -3 tools/gpt_check.py reply <номер беседы> <файл>`. Больше одного круга —
только если он принёс новый довод; спор ради спора не вести, разногласие показать Vitali.

## 4. Покажи Vitali оба мнения

Таблица: замечание Codex → твой вердикт → чем подтверждён (файл:строка). Отдельно — что Codex
не смог проверить без запуска. Если обе стороны согласны, что ошибок нет, — так и скажи одной строкой,
и напомни, чего статическая проверка не покрывает (сборка, дамп, прогон).

Подтверждённое в своей текущей правке — исправляй сразу (через `editq`, как обычно).
Подтверждённое в чужом или уже выпущенном коде — сначала покажи Vitali.
