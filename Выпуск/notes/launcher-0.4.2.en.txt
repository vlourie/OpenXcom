- Launcher 0.4.2: the setup from the site (XPiratezHD-Setup) and the launcher itself now show a proper name, company and version in the file properties (Properties → Details): "X-Piratez HD Setup" and "X-Piratez HD Launcher", company X-Piratez HD, and the same version as in the setup's file name. Before, it said "xp-bootstrap" and version 0.1.0.
- Launcher 0.4.2: an update now comes as one compressed archive even if you missed more than three releases. The site builds that archive on request (usually seconds, longer for a very old install) and keeps it for other players. If it is not ready within 3 minutes, disk space is low, or it would be bigger than the separate files, the launcher downloads file by file as before.
