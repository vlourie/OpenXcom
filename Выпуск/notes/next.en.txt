- Launcher 0.5.5: the window no longer freezes during self-update or while checking whether the game build knows mods: hashing and copying run in the background and the exe is read in 1 MB blocks instead of whole into memory. The voice key (push-to-talk) is listened to on its own thread. Unused code removed.
- Launcher 0.5.4: the device and ticket keys never leave with a redirect: the launcher talks only to the X-Piratez site, on the same address and port, and treats a redirect answer as an error. The setup loads its signature library only from itself, never from a file of the same name lying next to it in Downloads.
- Site: a Lua mod's description is read from the archive up to 64 KB of real data, whatever size the archive header claims.
- Battle and globe (HD): an error inside one HD frame drawing job is written to the log and the frame is finished without that slice, instead of the game closing.
- Lua mods: a mod that spends more than 100 million instructions in one turn is switched off with a line in the log instead of freezing the battle. The count starts again every turn of any side, at the start and end of a battle and every day on the globe. Game mechanics and the old per-call limits are unchanged.
