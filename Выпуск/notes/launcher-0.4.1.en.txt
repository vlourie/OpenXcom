- Launcher 0.4.1: a game update comes as one compressed archive again, not thousands of separate files. If you picked what to install (mods, HD art) at setup, the launcher did not see the ready update archives and always downloaded every changed file on its own. Now, if you missed three releases or fewer, the update comes as one file about a third of the size. If you missed more, it still comes file by file for now.
