- Saves: new "Compact saves (this OXCE only)" checkbox in the HD options, "Speed" tab. Each soldier's kill list is stored compactly and the save body is compressed: a late-game 36 MB save takes about 2.4 MB, is written about three times faster and loads faster. Nothing is lost. Off by default: such saves open only in this OXCE-HD build (this build always reads ordinary saves). The F8 report attaches an ordinary save.
- Launcher 0.5.6: a save written with the "Compact saves" option is unpacked into an ordinary save when a ticket is sent, so the site accepts it as before. A damaged compact save is named in the report and not sent.
