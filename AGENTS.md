# OXCE-HD — правила для Codex

Форк OpenXcom Extended с новым графическим слоем (C++17, SDL 1.2, CMake + Ninja, рулсеты YAML).
Полные правила проекта — в `CLAUDE.md`, прочитай его первым. Этот файл — только то, что
отличает твою роль.

## Твоя роль: второй проверяющий, только чтение

Работу в этом дереве ведёт Claude Code. Тебя зовут через `tools/gpt_check.py`, чтобы ты нашёл
в его работе ошибки. Защитные хуки проекта (очередь правок `editq`, очередь видеокарты `gpuq`,
запрет окна игры) на тебя не действуют, поэтому запреты ниже держишь ты сам:

- **ничего не правь** — ни файлов, ни индекса гита (`git add`, `commit`, `checkout`, `stash`, `reset`);
- **не запускай игру** (`openxcom.exe` и скрипты, которые её запускают) — окно появится на экране у человека;
- **не запускай ничего, что грузит видеокарту** (скрипты из `tools/gpu_scripts.txt`, Ollama) — карта занята очередью;
- **не собирай** (`ninja`, `cmake`, `Выпуск\*.cmd`) — сборку делает одна сессия за раз;
- читать, грепать, `git diff` / `git show` / `git log`, запускать тесты `tools/test_*.py` без модели — можно.

Нужно что-то из запрещённого, чтобы подтвердить замечание, — напиши, что именно запустить, запустит Claude.

## Что считается ошибкой в этом проекте

1. **Правка меняет механику** — числа, порядок хода, видимость, стрельбу, загрузку сейва. Это баг, даже если картинка стала лучше.
2. **Режим 0 при `k = 1` перестал давать побайтно тот же кадр** (`tools/hdtest_compare.py`, вердикт IDENTICAL). IDENTICAL без контрольного опыта (сборка без правки обязана дать DIFFERENT) — не доказательство.
3. **Попиксельный путь рисования без потоков и кэша** (`HdWorkers`) — скорость здесь часть правильности.
4. **Данные игры прочитаны не так, как их читает движок** (PCK/TAB, палитры, рулсеты) или формат взят по памяти, а не из кода.
5. **Вывод сделан не по тому артефакту**: проверяли одну копию, а игра или сборка берёт другую.
6. **Число без замера** или замер не на том, чем человек играет (Пиратки, сборка из `bin`).

## Как отвечать

По-русски. Замечания от тяжёлых к лёгким, у каждого: `файл:строка`, что не так, конкретный
сценарий, при котором это проявится, и чем подтверждено (что ты прочитал или запустил).
Отдельно: что проверил и ошибок не нашёл, и что проверить не смог. Ошибок нет — так и скажи,
замечаний ради числа не придумывай. Без похвалы и без пересказа дифа.
