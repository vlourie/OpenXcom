# OXCE-HD

Форк **OpenXcom Extended** (OXCE 8.7.0) с новым графическим слоем. Технологии: C++17, SDL 1.2, CMake + Ninja, ruleset YAML.

@docs/RAKES.md

## Что это за проект

Переписываем графику OpenXcom, **не трогая ни одной механики**. Оригинальный движок рисует
8-битной палитрой в 320×200; поверх него живёт второй, 32-битный слой, который при `k = 1`
обязан давать **побайтно тот же кадр**, а при `k > 1` — тот же кадр в увеличенном разрешении.
Проверка на совпадение — не формальность, а главный инструмент: она отделяет «стало красивее»
от «сломалось незаметно».

## Святое правило про данные игры

Если правка задевает `bin/common` или `bin/standard` (строки интерфейса, шрифты, ванильные
рулсеты), то обязательны три шага, все:

1. предупредить Vitali **до** правки;
2. перенести изменение в установку Пираток — `Пиратки\Dioxine_XPiratez\common` и `\standard`;
3. отдельно написать ему об этом, чтобы он повторил на второй машине.

Пропустить любой из трёх — значит разойтись с рабочей установкой и ловить это потом на глаз.

## Правила для всех агентов

1. **Сначала читай, потом делай.** `docs/PROJECT.md` и `docs/DECISIONS.md` — обязательны.
2. **Ничего не меняем в механике.** Любая правка, которая влияет на числа, порядок хода,
   видимость, стрельбу или загрузку сейва, — это баг, а не фича, даже если картинка стала лучше.
3. **`k = 1` обязан давать IDENTICAL.** Изменил путь рисования — сними дамп Ctrl+F8 и прогони
   `python tools/hdtest_compare.py`. «Глазами похоже» — не результат.
4. **Не угадывай форматы.** PCK/TAB, палитры, рулсеты, drawingRoutine — смотри в коде и в
   рулсетах Пираток, а не по памяти.
5. **Результат — файл, не сообщение.** Работа, существующая только в чате, не сделана.
6. **Не трогай `Пиратки/` и `bin/UFO`.** Это установленная игра и оригинальные данные.
7. **Минимальный диф.** Не рефактори попутно, не переименовывай «заодно».
8. **Скорость — часть правильности.** Попиксельная работа на 2560×1440 в один поток
   убивает игру. Новый путь рисования сразу проектируй под `HdWorkers` и кэш.
9. **Наступил на грабли — запиши немедленно.** `python tools/rake.py add ...`, не «потом».

## Сборка

MSYS2 не в постоянном PATH — добавляется только для текущей сессии:

```powershell
$env:Path = "C:\msys64\mingw64\bin;$env:Path"
cd build-release
cmake ..        # только если менялся CMakeLists
ninja
```

Пути тулчейна — `tools\build\build_config.json` (`MsysBin`) и `build-release\CMakeCache.txt`.
Сборка релиза с упаковкой DLL — `OXCE_Build.cmd` в корне.

Генерация арта живёт в своём окружении: `tools\hdart\.venv` (в системном `py -3` нет diffusers).

## Проверка изменений рендера

| Что | Как |
|---|---|
| дамп кадра | Ctrl+F8 в бою или на геоскейпе (опция `keyBattleHdTestDump`; просто F8 — отчёт игрока) → `hdtestNNN_map.png`, `_frame.png`, `.json` |
| сравнение | `python tools\hdtest_compare.py` — описание в `tools\hdtest_README.md` |
| режимы HD | F9 или опция `oxceHdMode`: 0 nearest, 1 паки, 2 паки + xBRZ |
| масштаб | `oxceHdScale` 1–4; режим 0 при любом `k` обязан быть IDENTICAL |

В поле `canvas` внутри `.json` записано, какая сборка снимала дамп, — при сравнении смотреть его.

## Технические рамки OpenXcom Extended

- Размеры спрайтов: база 32×40 (юниты, тайлы террейна), HD — `k ×` база, `k = BLANKS.PCK / 32`, максимум 4.
- Палитра: 8-битная индексная у классического слоя, рампы палитры мода; HD-кадры — PNG RGBA,
  тон берётся по рампам, индекс 0 прозрачный, рядом `.pal.txt`.
- Форматы: PCK/TAB и SCR/SPK у классики, PNG RGBA у HD-паков, ruleset YAML.
- Бюджет памяти: ленивая загрузка картинок в 768 МБ, кэш затенённых кадров 256 МБ.
- Как игра подхватывает мод: `user/mods/<id>/metadata.yml`, паки в `hd/<набор>/<кадр>.png`,
  террейн — `hd/TERRAIN/<имя>.PCK/`, картинки интерфейса — `hd/UI/<имя файла>.png`.

## Definition of Done

- [ ] собирается без новых предупреждений в своих файлах
- [ ] режим 0 при `k = 1` и `k = 4` даёт IDENTICAL против эталонного дампа
- [ ] замер `drawMs` / `flipMs` из `.json` не хуже предыдущего (см. `docs/PERF.md`)
- [ ] проверено и в ванильном UFO, и в Пиратках — рулсеты и наборы у них разные
- [ ] правки в `bin/common` / `bin/standard` перенесены в установку Пираток и озвучены
- [ ] грабли, на которые наступили, записаны в `docs/RAKES.md`
- [ ] `CHANGELOG.md` пополнен строкой на языке игрока

## Среда

- Windows, PowerShell. Разделитель строк в командах — перенос строки или `;`, **не** `^`.
- **Весь текст с кириллицей — UTF-8 со спецификацией** (грабли R-001): и `.ps1` (иначе
  не запустится), и всё, что генерят скрипты (иначе `type` печатает мусор).
  В python — `encoding="utf-8-sig"` на запись и на чтение. Читать файлы командой
  `Get-Content -Encoding UTF8`, а не `type`. Проверка `tools\fix_bom.ps1`, починка `-Fix`;
  хук `bom-guard` дописывает спецификацию в `.ps1` сам.
- **Перед командой с внешним инструментом — `Get-Command`** (грабли R-002).
- GPU: RTX 5090, 32 ГБ VRAM. Модели в `E:\models`.
- Локальная модель для черновых описаний модулей: Ollama + `qwen3.8:27b`.
  Источник смысла, не фактов: имена, сигнатуры и строки — только из `.index/symbols.tsv`.

## Стиль коммитов

`область: что сделано` — например `hdui: текст кнопок геоскейпа по центру рамки`.
Одно логическое изменение — один коммит.
