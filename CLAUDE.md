## Правила для всех агентов

1. **Сначала читай, потом делай.** `docs/PROJECT.md` и `docs/DECISIONS.md` — обязательны. Релевантные `docs/research/*.md` — тоже.
2. **Не угадывай форматы и API.** Неизвестно — зови `scout`. Выдуманное поле хуже отсутствующего.
3. **Результат — файл, не сообщение.** Работа, существующая только в чате, не сделана.
4. **Не трогай `game/`.** Оригинальные файлы игры не правим — только через штатный механизм модов.
5. **Минимальный диф.** Не рефактори попутно, не переименовывай «заодно».
6. **Записывай решение.** Всё, о чём можно поспорить позже, идёт в `docs/DECISIONS.md` одним абзацем.
7. **Ищи по карте, а не чтением.** Где объявлен символ — `grep -P '^Имя\t' .index/symbols.tsv`. Что есть в файле — `grep -P '\tпуть/к/файлу\t' .index/symbols.tsv`. Читай целиком только то, что собираешься менять.
8. **Наступил на грабли — запиши немедленно.** `python tools/rake.py add ...`. Не в конце задачи, не «потом»: через час ты забудешь формулировку, а в следующей сессии не вспомнишь вообще.

## Грабли: протокол

Список активных граблей выше по импорту `@docs/RAKES.md` — он в контексте с первой секунды.

| Наступил раз | Что обязан сделать |
|---|---|
| 1 | запись: `python tools/rake.py add --title ... --files ... --symptom ... --cause ... --rule ...` |
| 2 | **тест или хук** — текст не сработал. `python tools/rake.py hit R-0NN`, потом защита, потом `disarm` |
| 3 | правка архитектуры, чтобы так ошибиться было нельзя |

Текстовое правило — слабая защита: его можно прочитать и всё равно ошибиться.
Тест — сильная. Поэтому вторая встреча с теми же граблями закрывается только автоматикой.

Счётчик `Наступал:` занижать нельзя. Он единственная честная метрика того, работает система или нет.

## Definition of Done

Фича считается сделанной, когда:

- [ ] код собирается, мод загружается игрой без ошибок в логе
- [ ] заявленное поведение проверено воспроизводимыми шагами (`qa`)
- [ ] ассеты лежат в `assets/30_final` в формате игры и прошли чек-лист `asset-smith`
- [ ] нет новых TODO без пункта в `docs/BACKLOG.md`
- [ ] **исправленный баг закрыт регрессионным тестом**, названным по номеру граблей
- [ ] грабли, на которые наступили в ходе задачи, записаны в `docs/RAKES.md`
- [ ] `git-warden` дал «можно коммитить»
- [ ] `CHANGELOG.md` пополнен строкой на языке игрока

## Среда

- Windows, PowerShell. Разделитель строк в командах — перенос строки или `;`, **не** `^`.
- **Все `.ps1` — UTF-8 с BOM и CRLF.** Без BOM PowerShell 5.1 читает скрипт как cp1251
  и падает на кириллице (грабли R-001). Проверка `tools\fix_bom.ps1`, починка `-Fix`;
  хук `bom-guard` дописывает BOM сам после каждой записи.
- GPU: RTX 5090 (32 ГБ VRAM). Бэкенд генерации картинок: `tools/gen_gpu.py`.
- Локальная модель для черновых описаний модулей: Ollama + `qwen3.8:27b`, см. `tools/describe_modules.py`.
  Она источник СМЫСЛА, не фактов. Имена, сигнатуры и строки — только из `.index/symbols.tsv`.

## Стиль коммитов

`область: что сделано` — например `spawn: пираты не появляются в первую неделю`.
Одно логическое изменение — один коммит.
