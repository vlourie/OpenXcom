# Картинки сайта

Сюда кладутся изображения, которые отдаёт сервер. Правило строгого CSP не мешает картинкам,
но внешних адресов мы не используем: всё лежит здесь, рядом с сайтом.

| Что | Куда | Как подключается |
|---|---|---|
| кадр на главной | `img/<имя>.jpg` | `Portal:HeroImage` в настройках; пусто — на главной рисуется размеченная рамка, а не дыра |
| картинка мода | `img/mods/<имя>.jpg` | поле `image` в `deploy/seed/community.json` |

Размеры: кадр главной — не уже 1280 по ширине, соотношение примерно 16:10; картинка мода —
640×360 и больше, показывается полосой 120 px по высоте с обрезкой по центру.

Формат — JPEG для фотографий и кадров, PNG только там, где нужна прозрачность. Держать
каждый файл в пределах 300 КБ: страница мода грузится вместе со всеми карточками.

Картинки рисуются локально (Qwen-Image), лежат в репозитории и попадают в образ при сборке.
