Сайт поддержки OXCE-HD - тестовый запуск на своей машине
==========================================================

Нужно: Windows 11, Docker Desktop (запущен), интернет для первой сборки.
Чужие сайты в Docker не трогаются: порты 80 и 443 остаются им, у этого сайта свой порт (8443 или
первый свободный после него).

1. Распаковать архив в любую папку, например C:\xp-portal.

2. Открыть PowerShell в папке portal\deploy и запустить:

       powershell -ExecutionPolicy Bypass -File .\station.ps1

   Первый раз - 5-10 минут (скачиваются образы .NET, PostgreSQL, антивируса). В конце скрипт
   напишет адрес сайта, например https://192.168.1.50:8443

3. Создать себя администратором (пароль спросит, не показывая):

       powershell -ExecutionPolicy Bypass -File .\station.ps1 admin you@example.com Vitali

   Войти на сайт, «Безопасность» -> включить двухфакторную проверку (Google Authenticator и т.п.),
   выйти и войти снова с кодом. Без этого страницы команды не открываются.

Браузер один раз предупредит о сертификате: он выдан самим сайтом, а не Let's Encrypt.
Чтобы предупреждения не было (и чтобы лаунчер мог слать отчёты), см. команду root-cert.

Остальные команды - в шапке station.ps1: status, logs, mail, root-cert, down.
Данные (база, файлы, ключи) живут в томах Docker и переживают перезапуск и пересборку.

Для Claude на этой машине - файл CLAUDE.md в корне архива: открыть папку архива в Claude Code,
и он будет знать, как тут всё устроено.
