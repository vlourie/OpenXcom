# Тактический ИИ Пираток — проект

Составлено 2026-09-27. Статус: **проект, кода нет**. Решение и контракт честности —
`docs/DECISIONS.md` (2026-09-27), этапы — `docs/AI_ROADMAP.md`. Факты о родном ИИ, составе
врагов и инфраструктуре знания — `docs/research/native-ai-anatomy.md`,
`piratez-enemy-roles.md`, `ai-knowledge-infra.md`.

## Чего хотим

Бой, после которого у игрока горит. Не потому, что враг видит сквозь стены или получил
+30 к меткости, а потому, что он **воюет как отряд**: снайпер сидит в темноте и ждёт, пока
разведчик подсветит цель; стрелки двигаются парами, один бежит — второй держит сектор;
рукопашники заходят вне линий огня и бьют разом; раненый отходит; никто не выходит под
стену отстрела по одному.

Главный враг — игрок уровня Vitali (`docs/research/player-profile.md`): 53 % убийств
вплотную, 16 % на чужом ходу со стены отстрела, половина боёв в полной тьме, бой решается
за 5 ходов. Больно ему уже сейчас только в обороне базы — там, где противник приходит
сразу, плотно и с двух сторон. **Задача ИИ — делать каждый бой похожим на оборону базы.**

## Почему родной ИИ «вытворяет»

Родной ИИ OXCE — автомат из четырёх настроений (патруль, засада, бой, бегство), каждый юнит
решает за себя. Отсюда всё, что видно в бою:

- никто никого не ждёт — отряд приходит по одному и по одному умирает на стене отстрела;
- роли нет — снайпер с винтовкой ведёт себя как рукопашник с ножом;
- после одного взгляда `intelligence` ходов знает, где ты, — и при этом не пользуется этим
  тактически, а просто идёт к тебе;
- света и дыма не знает вовсе.

То есть он одновременно **читерит и тупит**. Убираем чит, чиним голову.

### Утечки родного ИИ — что закрывает опция

По `docs/research/native-ai-anatomy.md`, всё проверено по коду:

| Утечка | Где | Под опцией |
|---|---|---|
| `intelligence` ходов после взгляда — **текущая** позиция цели; ею пользуются выбор цели, рывок в рукопашную, пси, путевые точки, узлы | `AIModule.cpp:2952`, чтения `getPosition()` по всему файлу | вместо позиции — контакт из слоя «Знание» |
| снайперы OXCE стреляют по наводке своих N ходов — по текущей позиции | `getTurnsLeftSpottedForSnipersByFaction`, `Unit::getSpotterDuration` | наводка — да (это радио), но по клетке контакта |
| после 20-го хода или при ≤2 живых все пришельцы разом узнают, где игрок, и идут в бой | `SavedBattleGame.cpp:1539`, `AIModule.cpp:1998` | выключено: против затягивания — замысел ПОИСК |
| подбор оружия: видит все предметы, брошенные за ход на всей карте | `BattlescapeGame::surveyItems`, `:2665` | только предметы на клетках, которые видел кто-то из своих |
| `sneakyAI`: путь дороже по клеткам, которые видит *любой* юнит | `Pathfinding.cpp:181` | у Пираток выключено; под опцией не используется — есть карта угроз |

Опасная зона от взрыва (`setDangerZone`, `TileEngine.cpp:5933`) — не утечка: гранату видят все.
Юнит думает не больше двух раз за ход (`BattlescapeGame.cpp:312`) — штабу и ролям нужно
больше; это ограничение надо снять под опцией, иначе «выглянуть — доложить — спрятаться»
не уложится.

## Устройство: три слоя

```
  ┌───────────────────────────────────────────────┐
  │ 1. Знание      что сторона знает о противнике │  ← только честные источники
  ├───────────────────────────────────────────────┤
  │ 2. Штаб        раз в ход: угрозы, замысел,    │  ← один раз на сторону
  │                роли, очерёдность              │
  ├───────────────────────────────────────────────┤
  │ 3. Боец        клетка и действие по роли:     │  ← на каждого юнита
  │                жёсткий отсев, потом оценка    │
  └───────────────────────────────────────────────┘
```

Родной `AIModule` остаётся: слой 3 зовёт его для того, что он и так умеет (выстрел,
граната, путь). Новый код — отдельный модуль `src/Battlescape/AiTactics.*`, вход в него из
`AIModule::think` под опцией. Всё — в нашем дереве, проверка — на Пиратках (форк Brutal не
используем, DECISIONS 2026-09-27).

## Слой 1. Знание

### Запись о контакте

Сторона ИИ хранит не «видимых врагов», а **контакты**:

| Поле | Смысл |
|---|---|
| кто | номер юнита, если его видели глазами; «неизвестный», если только слышали |
| где | клетка последнего наблюдения |
| когда | ход и фаза (свой / чужой ход) |
| источник | глаз, слух, огонь по нам, доклад |
| точность | радиус неопределённости: 0 для глаза, растёт от расстояния для слуха |
| оружие | тип, если видели в руках (спрайт — как видит игрок); иначе неизвестно |
| скорость | оценка клеток за ход — см. ниже |

Неопределённость растёт со временем: через ход после наблюдения враг может быть где угодно
в радиусе «оценка скорости × ходы». Это и есть честная замена родному «знаю, где ты».

### Источники — только эти

1. **Глаз.** Юнит ИИ увидел врага — запись в *личную* память юнита.
2. **Слух.** Эталон — что получает игрок (`ai-knowledge-infra.md`): звук выстрела у него
   всегда на полной громкости, без дальности (`Sound::play`, `distance` всегда 0), только стерео
   направление; трасса и точка вылета видны, лишь если клетка вылета видна игроку
   (`Map::_projectileInFOV`, `Map.cpp:483`). Честное зеркало для ИИ: каждый слышавший получает
   **пеленг** на стрелка с погрешностью (порядка ±15°) без дальности; клетка вылета видна
   кому-то из ИИ — точная позиция. Несколько пеленгов от разных бойцов, сведённые докладом,
   дают засечку — так поступил бы и живой отряд.
   **По звуку узнаётся тип оружия** (решение 27.09): звук выстрела — `fireSound` оружия. Звуков
   у Пираток 153 на 747 ссылок, один звук бывает у многих стволов, поэтому по звуку контакт
   получает не одно оружие, а **список возможных** — те, у которых такой `fireSound`; дальность
   и мощность берутся осторожной оценкой по этому списку.
3. **Огонь по нам.** В юнита попали или пролетело рядом — направление на стрелка
   (как стрелки по Alt у игрока).
4. **Доклад.** Личная память переходит в общую картину стороны — **сразу всей стороне**, без
   радиуса (решение 27.09), — только если юнит **жив и в сознании** в момент доклада — после
   завершения своего шага или действия. Убит
   реакцией на том же шаге, где увидел, — знание пропало. Оглушён — пропало до пробуждения.

### Что не знает никогда (без источника)

- **Броня.** Параметры брони игрока — только если сторона ИИ **хоть раз брала в плен** бойца
  в такой броне (знание кампании, живёт между боями). Иначе урон оценивается по
  нейтральной догадке — как по собственной броне ИИ.
  **Плена бойцов в OXCE и Пиратках нет** (`ai-knowledge-infra.md`): боец, оставшийся без
  сознания или не дошедший до выхода на проигранном задании, помечается MIA и удаляется
  (`DebriefingState.cpp:1710`, `SavedGame::killSoldier`). Предложение — считать такого бойца
  взятым в плен *для знания*: механика не меняется (боец потерян так же), а сторона-победитель
  запоминает его броню. Хранилище — новый необязательный ключ в сейве кампании (готовое
  `SavedGame::_scriptValues` для набора броней неудобно). **Принято 27.09.**
- **Скорость.** Сколько клеток ходит боец — только оценка: стартовая догадка «как свой
  средний юнит», дальше поправка по наблюдению: видели в клетке A на ходу k и в клетке B на
  ходу k+1 — значит, он проходит не меньше |AB|. Оценка только растёт.
- **Состав отряда, ОВ, здоровье, раны, характеристики.** Здоровье — только по наблюдаемому:
  «ранен» (видели попадание) да/нет.
- **Позиция невидимого.** Никакого `getPosition()` у врага, которого сейчас никто не видит.

Почему нужен свой слой, а не правка родного: в движке знание фракции записывается **на цель**
(`BattleUnit::_turnsSinceSpotted[фракция]`, `TileEngine.cpp:1500`), без того, кто видел, —
его нельзя отозвать, когда наблюдатель погиб, и в нём нет ни клетки, ни хода наблюдения.
Движок этим пользуется и для обычной игры, поэтому его не трогаем: контакты ИИ — отдельная
структура нового модуля, по образцу `_turnsSinceSpotted` пишется в сейв необязательным ключом
(`tryWriteAs` с умолчанием; старая сборка незнакомый ключ не спрашивает — `Yaml.h:391`).

### Тест слепоты — контракт проверяется автоматически

Берём сохранённый бой и **меняем то, чего ИИ знать не должен**: переставляем невидимых
бойцов игрока, меняем им броню, ОВ, здоровье. Первое решение каждого юнита ИИ (`[AIDECIDE]`)
обязано совпасть до знака. Не совпало — где-то утечка, и тест показывает, у какого юнита.
Это тот же приём, что IDENTICAL для графики: честность не на словах, а проверкой.
Контрольный опыт: на родном ИИ тест обязан **упасть** — он подглядывает.

## Слой 2. Штаб — раз в ход на сторону

До того, как пойдёт первый юнит:

1. **Карта угроз.** Для каждого контакта — зона, откуда он сможет увидеть и выстрелить после
   своего хода: круг неопределённости, раздутый на оценку скорости, с проверкой линии
   видимости. Итог — для каждой клетки «сколько контактов могут её достать и как легко».
   Это честная версия `discoverThreat` из Brutal: по догадкам, а не по настоящим ОВ врага.
2. **Замысел** на ход, один на группу (группа — юниты рядом, 2–6 человек):

   | Замысел | Когда |
   |---|---|
   | ПОИСК | контактов нет или все старые: разведчики вперёд, остальные ждут вне угроз |
   | ЗАСАДА | контакт идёт к нам (приближался два наблюдения подряд) или у нас объект обороны |
   | НАТИСК | контакт свежий, наших, способных ударить **в этот же ход**, достаточно — идут все разом |
   | ОБХВАТ | натиска не хватает: часть держит, рукопашники и быстрые обходят вне угроз |
   | ОТХОД | потери выше порога, или противник сильнее по оценке — к своим, в темноту |

3. **Правило «не по одному».** Юнит, который в этот ход не дойдёт до огневого контакта вместе
   с группой, не выходит в зону угроз — ждёт на рубеже вне видимости. Лучше потерять ход,
   чем подарить игроку выстрел на реакции.
4. **Очерёдность.** Сначала разведчик (открыть цель), потом стрелки и снайперы (выстрелить),
   потом рукопашники (добить), потом отстающие. Кто в дверях — первым (из Brutal).
5. **Свет.** Ночью, если по нам стреляют из темноты или контакт в тёмной зоне, — осветительный
   туда первым действием хода. Осветительные врагам Пираток выдаются модом (решение 27.09,
   ниже «Снаряжение»); если у юнита их всё же нет — держаться своих тёмных клеток.

## Слой 3. Боец — клетка и действие по роли

Роль определяется по снаряжению в начале боя (классификатор — по данным оружия Пираток,
см. `piratez-enemy-roles.md`) и может смениться, если оружие потеряно или подобрано.

Что говорит состав Пираток (разведка 27.09, все 9190 наборов снаряжения 489 развёртываний):

- **Роль — по оружию в руках, а не по типу юнита.** У «человеческих» фракций (бандиты,
  наёмники, правительство, культы — 52 % типов) оружие выдаёт развёртывание по слоту ранга,
  и один тип на одной карте бывает и с винтовкой, и с ножом. У монстров, роботов, нежити
  оружие встроено в тип.
- Доли основного оружия: винтовка 26 %, пистолет 24 %, дробовик 11,5 %, гранатомёт / РПГ /
  миномёт 11,3 %, рукопашное 11,1 %, пулемёт / автомат 7,8 %, **настоящая снайперка — 1 %**,
  пси 0,4 %, медикит 0,3 %.
- Значит, **снайпер — это не ствол, а роль в группе**: лучший дальний стрелок группы (винтовка
  с высокой прицельной точностью и дальностью) берёт роль снайпера, остальные винтовки —
  стрелки. Пистолет и дробовик — треть всех врагов — это ближний стрелок (см. таблицу).
- Механика OXCE «спотер — снайпер» у Пираток живая: поле `sniper` у 169 типов, `spotter` у 183 —
  турели, командиры, боссы. Пара «разведчик подсвечивает — снайпер стреляет» опирается на неё
  (по клетке контакта, см. утечки).
- `isLeeroyJenkins` — 16 типов, вся нежить и пара берсерков: у них своя простая ветка, нежити
  так и положено. Роли их не трогают.
- Пси — только верхний ярус (боссы, лидеры). Медиков как архетипа нет: «аптечка» у врагов почти
  всегда выпивка и сигареты. Роль «медик» — на потом.
- Газовые гранаты (`STR_GAS_GRENADE`) есть по-настоящему — 467 раз в 86 развёртываниях.
  Осветительных нет: `BT_FLARE` у Пираток в 90 % случаев — лут, настоящий свет несут 7 уникальных
  юнитов. Отсюда решение выдавать их модом.

Выбор клетки у каждого — **сначала жёсткий отсев, потом оценка**. Множители к оценке уже
проверены и не работают (R-034): клетка должна не дешеветь, а исчезать из рассмотрения.

| Роль | Чего хочет | Жёсткий отсев | Действие |
|---|---|---|---|
| **Снайпер** | видеть подходы издалека, не быть видимым | клетки в зоне угроз; ближе своей дальности до любого контакта; освещённые, если противник в темноте | прицельный с максимальной дистанции; держит ОВ на реакцию; выстрелил — его засекли по звуку — следующий ход новая позиция |
| **Разведчик** (быстрый, лёгкий) | открыть цель и уйти | клетки, откуда не вернуться за угол в этот же ход | выглянуть — доложить — спрятаться (подглядывание из Brutal); первым в очереди |
| **Стрелок** | огонь из укрытия, парой | клетки в зоне угроз без укрытия; ближе рукопашной дальности замеченного рукопашника | перебежки парой: один идёт, второй держит ОВ на реакцию; конец хода — только в укрытии |
| **Ближний стрелок** (пистолет, дробовик — треть врагов) | выстрел с короткой дистанции из-за угла | открытые клетки на подходе; клетки в зоне угроз дальше своей дальности | подходит вне видимости вместе с рукопашниками, стреляет в упор из-за угла, в поле не выходит |
| **Пулемётчик / подавление** | держать сектор | открытые клетки | стоит на подходе и копит ОВ на реакцию — зеркало стены отстрела игрока |
| **Рукопашник** | ударить, не попав под огонь | путь через клетки в зоне угроз (кроме последнего броска); открытые освещённые клетки | подходит вне линий огня и в темноте, ждёт на дистанции броска; бьёт, только когда хватает ОВ дойти и ударить, и лучше вместе с другими |
| **Гранатомётчик** | выкурить из укрытия | клетки, где взрыв зацепит своих | граната в скопление или в укрытие контакта; дым перед перебежкой своих |
| **Пси** | работать, не показываясь | любые клетки, видимые врагу | пси по видимому, приоритет — ударный рукопашник игрока |
| **Зверь** (без рук) | стая | заход с одной стороны с другими зверями | обход с разных направлений, раненый отходит |
| **Командир** | жить | передняя линия | сзади, в укрытии; его гибель бьёт по морали (движок уже умеет) |
| **Медик** | поднять своих | зона угроз | лечит раненых у себя за спиной |

Общие правила для всех ролей:

- **Раненый отходит** (порог по здоровью), если не может убить в этот ход.
- **Не стрелять по своим** и не кучковаться под гранату (из Brutal).
- **Ночь.** Клетки, освещённые светом игрока или пожаром, штрафуются жёстким отсевом для
  всех, кроме натиска.
- **Звук своего выстрела.** Выстрелил — считай, что тебя слышали: для следующего хода твоя
  клетка «известна» противнику.

## Цена — бюджет на Пиратках

Родной ИИ думает 3,2 с на ход стороны на крупном корабле, Brutal — 672 с. Бюджет — не дольше
двух родных, около 6 с на той же фикстуре (USO Dreadnought).

- карта угроз — один раз на сторону за ход, по контактам (их единицы, а не сотни юнитов);
- для бойца — не все достижимые клетки, а отсев по кольцам расстояния и по зоне угроз до
  дорогих проверок видимости;
- проверки видимости — с кэшем на ход; перебор клеток — под `HdWorkers` (R-009),
  при равных очках порядок фиксирован, чтобы решения не зависели от числа потоков.

## Сейв

- **Бой:** контакты стороны, роли, замысел групп — необязательный ключ в сейве боя.
  Старая сборка его пропустит (проверить по `load()`, см. `ai-knowledge-infra.md`).
- **Кампания:** список броней, которые сторона ИИ видела в плену, — необязательный ключ
  в сейве кампании.
- Опция выключена — ни одного нового ключа не пишется.
