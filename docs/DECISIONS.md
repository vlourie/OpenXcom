# Журнал решений

Новое — сверху. Старые записи не переписываем: если решение изменилось, пишем новую запись со ссылкой на старую.

Формат:

```
## <дата> — <решение одной строкой>
Контекст: что заставило выбирать.
Решение: что выбрали.
Причина: почему именно это.
Последствия: чем расплачиваемся, что теперь нельзя.
```
