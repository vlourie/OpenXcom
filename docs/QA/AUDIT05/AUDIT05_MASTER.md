## 6. Что нужно решить до этапа B

1. **Сторонний код** (`libs/` — 79,7 тыс. строк; внутри `src` — 33,9 тыс.: lodepng, md5, hq/xBRZ, Adlib, FLC,
   stb_truetype). Предложение: само содержимое не аудировать (`OUT_OF_SCOPE`), проверять только границу — что и
   с какими размерами мы туда передаём, особенно недоверенные данные (PNG, сейвы, YAML, Lua).
2. **Глубина по 397 тыс. строк.** Прочитать всё построчно одной сессией с одинаковой глубиной нельзя, и обещать это
   нечестно. Предложение — три уровня с честной отметкой в покрытии:
   полностью (`REVIEWED`) — ядро этапов B–D и загрузчики этапа F, около 125 тыс. строк;
   по функциям (`PARTIAL`) — геоскейп, база, инвентарь, генерация боя;
   по образцам и поиском шаблонов — 416 файлов экранов `*State` (112 тыс. строк), где логики мало.
3. **Дополнительные агенты.** Задание запрещает их без разрешения. Просмотр экранов `*State` по шаблонам —
   однотипная работа; с разрешением её можно отдать субагентам sonnet (число назову до запуска), без него — сам,
   дольше.
4. **Linux для TSan, LSan, MSan.** На Windows их нет, WSL не установлен. Варианты: поставить WSL здесь;
   гонять на удалённой Linux-машине; ограничиться заданиями GitHub (но задание запрещает отправлять туда
   диагностические правки, так что новые тесты туда не попадут).
5. **Стенд ИИ** (`AiProbe`, `Collapse*`, `AiCandidates`, `AiCoverMap` — 11,4 тыс. строк): аудировать как часть игры
   или только то, что исполняется у игрока.
