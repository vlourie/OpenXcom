## Дефекты и замечания

Новых дефектов изменения StartState не обнаружено.

### Существующие сообщения установленных модов

Воспроизведение: запустить baseline или fixed с исходным набором Piratez модов из копии `GAME/user/options.cfg`.
Ожидалось / получилось: загрузка без диагностик / у обоих по 89 одинаковых `ufopaedia item misses type_id attribute`, одинаковые два предупреждения о формате версий OAK-RU/XPZ_EX_RU-patch и 152 HD-изображения без соответствующего имени. Игра после этого загружается. Это существующий фон данных, не появившийся из-за исправления. У старого collapse-сейва дополнительно 17 предупреждений о неподходящих предметах инвентаря корабля; бой загружен.
Серьёзность: мелкий для приёмки этого исправления; причины данных отдельно не исследовались.

### Некорректная проба старого сейва — повтор R-087 в процедуре QA

Воспроизведение: взять `Пиратки/Dioxine_XPiratez/user/xcom1/quicksave.sav`, выбрать master по имени папки (`xcom1`) и загрузить копию через `--master xcom1`.
Ожидалось / получилось: ошибочно ожидался UFO-сейв / заголовок `mods` в самом сейве содержит piratez v.o1.1.1; загрузка Piratez-сейва ванильными правилами дала многочисленные Failed to load item/craft и Segmentation fault. Дамп не создан. Результат исключён из доказательства совместимости; корректный Piratez-сейв проверен отдельно выше. Это ошибка выбора входа проверки, а не доказанный дефект одноcтрочного исправления. Директор уведомлён для фиксации `rake.py hit R-087`.
Серьёзность: важный для достоверности QA. Порожденный процесс с аварийным диалогом на скрытом столе завершён по точному PID 28392 после проверки CommandLine; остальные валидные процессы завершились сами с кодом 0. После прогонов процессов openxcom/baseline не осталось.

## Не проверено и почему

- Полностью чистый профиль с интерактивным выбором языка, gentle/adult: валидные профили создавались отдельно, но cfg скопирован из установленного и вопросы выключены. R-036 полностью на чистом профиле не закрыт этим прогоном; исходная проверка активного strings-мода не изменена.
- Слышимая озвучка и её синхронизация: hidden harness задаёт musicVolume=0; R-032 остаётся штатным поведением. Проверка доказывает показ интро, но не слышимость. Громкость пользователя правка не меняет.
- Runtime reload через UI и выбор другого арта: закрыты C++-матрицей, не UI-переходами.
- Ванильное FLC-интро и настоящий старый UFO-сейв: проверено только меню UFO. Лежавший в xcom1 сейв фактически Piratez.
- Полное прохождение 16 слайдов, пропуск интро клавишей, отсутствующий ассет, предельные значения, длинные имена: не проверены.
- Режим 0 k=1/k=4 с картой и контрольным опытом, drawMs/flipMs бенчмарк: путь рендера не изменён; кадр меню IDENTICAL выше не заменяет такую регрессию.
- Все остальные активные записи RAKES: общий прогон всех подсистем не выполнялся. Прочитаны тематические R-029/R-032/R-033/R-036/R-087/R-108 и match для StartState (включая R-026); воспроизводимого повторного дефекта в production-пути не найдено.
- Финальный коммит, состав выпуска, подпись и запуск именно упакованного exe: на момент приёмки ещё не созданы; SHA свежей сборки дан выше для последующей сверки R-087. R-108 требует git show --stat и git status после коммита.
