# ИИ Пираток — как учим

Составлено 2026-09-29. Устройство ИИ — `docs/AI_DESIGN.md` (знание, штаб, боец), этапы —
`docs/AI_ROADMAP.md`. Здесь — **как делаем его лучше и как это меряем**.

## Слово Vitali (28–29.09)

- ИИ **знает карту** (всю местность) и **сколько бойцов самое большее** влезает в корабль, который
  сел (вместимость корабля из рулсета). Где сел корабль — знает: посадку видно.
- **Не знает** сколько бойцов вышло, где они после первого хода и **сколько клеток они проходят**
  (ОВ, характеристики, броня — нет).
- Каждый ход боец **просчитывает все клетки вокруг себя**, куда успеет дойти, и из каждой — всё,
  что оттуда можно сделать, и сравнивает по шансу: например, выстрел вблизи с большей вероятностью
  против прицельного издалека из укрытия.
- Сила — не в читах, а в расчёте: цель — играть **лучше человека**.
- Учить и **боями**, и **каждой клеткой** (разбором отдельных решений). Порции боёв — короткие.

## Оценка хода бойца — одна формула на все действия

Кандидаты: каждая клетка, куда боец успевает дойти (`Pathfinding::findReachable` по его ОВ),
плюс «остаться». Для каждой клетки — каждое действие оттуда: выстрел каждым режимом (навскидку,
прицельный, очередь) по каждому известному врагу, удар, бросок гранаты в клетку, лечение,
перезарядка, достать оружие из рюкзака, поднять с пола, присесть и держать ОВ на реакцию.

```
цена = урон_врагу − λ_риск · урон_себе − λ_ов · недостача_ОВ_на_реакцию + λ_цель · продвижение
урон_врагу = P(попадания) · P(пробить броню этой стороны) · урон     (формулы движка)
урон_себе  = Σ по вероятным врагам  P(враг там) · P(он достанет клетку) · его урон
```

- **Шанс попадания и урон — формулы самого движка** (`BattleUnit::getFiringAccuracy`, дальность
  и падение точности `RuleItem`, линия огня `TileEngine`), а не догадка. Вблизи точнее, но
  опаснее — это и есть выбор, который делает формула.
- **Где враги — карта вероятностей**, а не их настоящие клетки (`AI_DESIGN.md`, слой «Знание»):
  начало — клетки корабля; каждый ход растекается на **оценку** хода противника (стартовая
  догадка — средний свой юнит; видели A→B за ход — не меньше |AB|; оценка только растёт);
  клетка, которую видит кто-то из своих, и там пусто — обнуляется; выстрел, звук, раненый
  стягивают вероятность. Число врагов — не больше вместимости корабля, не меньше, чем видели разом.
- Жёсткий отсев клеток до оценки (R-034: множители не работают): клетки, где боец умрёт с
  заметной вероятностью, если не убивает в этот ход.
- Лучшая клетка и действие — исполнить; осталось ОВ — повторить перебор.

Бот за игрока и враг считают **одной и той же** оценкой, каждый — по своему знанию.
Бот за игрока — первым: его успех меряется просто (потери), и он же — честный соперник для врага.

## Два способа учить

### 1. Каждой клеткой — разбор решений (быстро, тысячи примеров за бой)

Движок пишет в лог **на каждое решение** строку `[AITILE]`: клетка, признаки, известные стороне
(сколько вероятных врагов её достают, укрытие по сторонам, свет, присед, куда смотрит, дистанция до
ближайшего контакта, ОВ в запасе), и что выбрано. А на ходу противника — **что с этой клеткой
случилось**: попали ли в бойца, сколько урона, убили ли.

Из этого питоном по сериям стенда:
- **Модель опасности клетки**: P(в бойца попадут до его следующего хода | признаки). Логистическая
  регрессия по сотням тысяч строк — какие признаки убивают на самом деле, с весами. Это λ_риск и
  «урон_себе» из данных, а не на глаз.
- **Калибровка шанса**: предсказанный шанс попадания против сыгранного исхода — формула обязана
  совпадать с игрой (иначе в ней ошибка).
- **Ходы Vitali** (когда будут сохранения каждого хода его боёв): его выбор должен попадать в
  верх списка оценки; где не попадает — там у оценки пробел.

### 2. Боями — парные порции

- Порция — **10 зёрен × 22 миссии = 220 боёв** на сторону, те же бои для A и B
  (`E:\OXCE_AIWorker\source\ai_ab.py`: пары по зерну и миссии, интервал бутстрепом).
- После каждой порции вердикт по убитым за бой: ЛУЧШЕ / ХУЖЕ / БЕСПОЛЕЗНО (эффект меньше 0,05) /
  ЕЩЁ (следующая порция). Серию из 1100 боёв подряд больше не ставим.
- Веса формулы (λ) подбирает перебор: несколько вариантов весов в очереди, лучший — следующая база.
- В очереди второй машины всегда есть хвост из продолжения текущей пары — пустеть ей нельзя.

## Порядок работ

1. **`[AITILE]`** — строка решения и исход клетки на ходу противника; поведение не меняется
   («выключено = как было» по отпечаткам). Порция на второй машине — первый набор данных.
2. **Модель опасности** по этим данным — какие признаки клетки убивают.
3. **Оценка хода** (`src/Battlescape/AiTactics.*`) для бота за игрока: перебор клеток и действий по
   формуле; парные порции против нынешнего бота.
4. **Слой «Знание»** для врага: корабль и его вместимость, карта вероятностей, оценка скорости,
   без пяти утечек родного ИИ (`AI_DESIGN.md`).
5. **Враг на той же оценке**, подбор весов порциями против бота.
