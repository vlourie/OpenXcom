# Настройка рабочей станции

Один раз на машине:

```powershell
.\tools\setup_workstation.ps1
```

Скрипт пропускает то, что уже стоит, и в конце печатает, что не встало.
`-WhatIfOnly` — посмотреть без установки. `-SkipModel` — без 18 ГБ модели.

## Что и зачем

| Программа | Зачем | Без неё |
|---|---|---|
| **universal-ctags** | символы: где что объявлено | карта проекта пустая, агенты читают файлы целиком |
| **clangd** (LLVM) | точный C++ индекс с типами | ctags путает перегрузки и шаблоны |
| **doxygen + graphviz** | граф вызовов и наследования | нет ответа «кто это вызывает» |
| **Python 3** | `index_project.py`, `rake.py` | не работает ни карта, ни грабли |
| **ImageMagick** | ресайз, палитра, конвертация | `asset-smith` бессилен |
| **oxipng** | сжатие PNG без потерь | ассеты тяжелее, чем нужно |
| **Ollama + Qwen3.8-27B** | черновые описания модулей | нет `.index/files.md`, остальное работает |
| **ComfyUI или Forge** | генерация картинок на GPU | `gpu-forge` не запускается |

Минимум, без которого система не работает: **Python + ctags**. Остальное улучшает.

## Локальная модель

```powershell
winget install Ollama.Ollama
ollama pull qwen3.8:27b     # ~18 ГБ, контекст 256K
python tools\describe_modules.py --check
```

На 5090 (32 ГБ VRAM) `qwen3.8:27b` идёт целиком в видеопамять. MoE-вариант
`Qwen3.8-2.4T-A95B` на одну карту не помещается — не пытайся.

Сменить модель: переменная `LOCAL_MODEL` или правка `.claude/settings.json`.

**Граница ответственности локальной модели.** Она пишет `.index/files.md` —
смысловые описания модулей. Это черновик. Имена функций, сигнатуры и номера
строк берутся только из `.index/symbols.tsv`, собранного ctags. Модель на 27B
уверенно выдумывает имена, которых в коде нет, и для карты кода это худший
тип ошибки — хуже, чем отсутствие описания.

## Генерация картинок

```powershell
python tools\gen_gpu.py --check
```

Скажет, поднят ли бэкенд, и что ставить, если нет. Для 50-й серии нужен
PyTorch с cu128 или новее — сборки под cu121 на Blackwell не заводятся.

## Проверка, что всё на месте

```powershell
python tools\index_project.py
python tools\rake.py list
```

Первая команда должна отчитаться числом файлов и символов. Если символов ноль —
не установлен ctags.
