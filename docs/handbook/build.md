## Сборка

MSYS2 не в постоянном PATH — добавляется только для текущей сессии:

```powershell
$env:Path = "C:\msys64\mingw64\bin;$env:Path"
cd build-release
cmake ..        # только если менялся CMakeLists
ninja
```

Пути тулчейна — `tools\build\build_config.json` (`MsysBin`) и `build-release\CMakeCache.txt`.
Сборка релиза с упаковкой DLL — `Выпуск\OXCE_Build.cmd`. Сборка + подпись + публикация +
архив для станции одним запуском — `Выпуск\OXCE_Release.cmd` (настройки `Выпуск\release_config.json`).

## Очередь правок игры

`tools/editq.py`: в одном дереве работают несколько сессий.
Файлы игры (`src/`, `bin/common`, `bin/standard`, моды, `CHANGELOG.md`, `Выпуск/notes`; список —
`tools/editq_paths.txt`) и сборку правит одна сессия за раз: хук сам занимает свободную очередь,
а занятую — отклоняет правку и велит ждать `py -3 tools/editq.py wait --name "<о чём>"`.
Закончил и проверил — `py -3 tools/editq.py done -m "область: что сделано"`: соберёт, закоммитит
**только свои** файлы (`--add` — дописать доки), отдаст очередь следующему. Ждёшь ответа Vitali —
`pause "о чём"`. Опустела очередь — через 15 минут сам идёт выпуск для игроков (`release.ps1`,
stable); инструкция для станции — `.editq/release_last.txt`, всё состояние — `editq.py list`.
`git add -A` / `git add .` / `git commit -a` хук запрещает всем. Тест — `tools/test_editq.py`.

## Очередь видеокарты

Всё, что грузит модель на видеокарту (генерация, обучение LoRA, описания через Ollama),
запускается только через очередь: `py -3 tools\gpuq.py add --name <имя> -- <интерпретатор> <скрипт> ...`.
Одно задание на карте, следующее стартует само; Ollama диспетчер выгружает сам. Порядок раздаёт
Vitali («срочно» — `urgent`, «вторым» — `move ID 2`, «до X» — `before ID X`); что идёт — `gpuq.py list`.
Приоритет `--prio`: 0 приёмка и регрессия, 1 по умолчанию (пилот, пробы), 2 эксперименты, 9 педия —
**педию ставить только `--prio 9 --preemptible`**: она уступает карту любому заданию выше после текущей картинки.
Прямой запуск агентом останавливает хук `gpu-guard` (тест `tools/test_gpu_guard.py`); список
скриптов с моделью — `tools/gpu_scripts.txt`, новый скрипт дописывать туда.

## Генерация арта

Генерация арта живёт в своём окружении: `tools\hdart\.venv` (в системном `py -3` нет diffusers).

**Ракурс боя — один на все генераторы.** Любой промпт графики боевой карты (пол, стены, предметы, юниты,
предметы на полу и в руке, эффекты, курсор) берёт блок ракурса и света из `tools/hdart/battle_view.py`
(`prompt_block(<вид>)`, направления юнита — `facing(dir)`), а не пишет его своими словами. Справку и проверку
промпта даёт агент `view-keeper`; кто ещё пишет своими словами — `battle_view.py audit`. Почему такие числа —
`docs/research/battle-render.md`. Одобренные промпты серий переводятся на модуль только со слова Vitali.

## Машина

- GPU: RTX 5090, 32 ГБ VRAM. Модели в `E:\models`.
- Локальная модель для черновых описаний модулей: Ollama + `qwen3.8:27b`.
  Источник смысла, не фактов: имена, сигнатуры и строки — только из `.index/symbols.tsv`.
- Проверка BOM — `tools\fix_bom.ps1`, починка `-Fix`; хук `bom-guard` дописывает спецификацию в `.ps1` сам.
