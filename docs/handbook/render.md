## Проверка изменений рендера

| Что | Как |
|---|---|
| дамп кадра | Ctrl+F8 в бою или на геоскейпе (опция `keyBattleHdTestDump`; просто F8 — отчёт игрока) → `hdtestNNN_map.png`, `_frame.png`, `.json` |
| сравнение | `python tools\hdtest_compare.py` — описание в `tools\hdtest_README.md` |
| режимы HD | F11 в бою или опция `oxceHdMode`: 0 nearest, 1 паки, 2 паки + xBRZ |
| масштаб | `oxceHdScale` 1–4; режим 0 при любом `k` обязан быть IDENTICAL |
| проверка экранов | живой стенд `py -3.13 tools\hdbench.py start --name A` (загрузка один раз, ~24 с), затем `run --name A "click 448,52; waitstate BasescapeState 5000; shot E:/tmp/x.png"` — кадр за 1–3 с, `set опция=значение; reinit` без перезапуска; справка — в начале `tools\hdbench.py`, спецификация — `docs/research/hd-test-bench-2026-10-26.md`. `tools\game_hidden.py` — только для одиночного кадра |

В поле `canvas` внутри `.json` записано, какая сборка снимала дамп, — при сравнении смотреть его.

## Технические рамки OpenXcom Extended

- Размеры спрайтов: база 32×40 (юниты, тайлы террейна), HD — `k ×` база, `k = BLANKS.PCK / 32`, максимум 4.
- Палитра: 8-битная индексная у классического слоя, рампы палитры мода; HD-кадры — PNG RGBA,
  тон берётся по рампам, индекс 0 прозрачный, рядом `.pal.txt`.
- Форматы: PCK/TAB и SCR/SPK у классики, PNG RGBA у HD-паков, ruleset YAML.
- Бюджет памяти (ленивая загрузка, числа в коде): кадры паков 384 МБ (`HdSprites`, для теста
  `OXCE_HD_PACK_BUDGET`), картинки интерфейса 768 МБ (`HdUiArt`), картинки базы 64 МБ (`HdBase`),
  кэш затенённых и освещённых кадров 512 МБ (с 21.10), стыки пола 640 МБ (затенённые сразу, с 20.10; для теста
  `OXCE_HD_GROUND_CAP` / `OXCE_HD_TONED_CAP`). Сколько занято на деле — `docs/PERF.md`.
- Как игра подхватывает мод: `user/mods/<id>/metadata.yml`, паки в `hd/<набор>/<кадр>.png`,
  террейн — `hd/TERRAIN/<имя>.PCK/`, картинки интерфейса — `hd/UI/<имя файла>.png`.

## Definition of Done

- [ ] собирается без новых предупреждений в своих файлах
- [ ] режим 0 при `k = 1` и `k = 4` даёт IDENTICAL против эталонного дампа
- [ ] замер `drawMs` / `flipMs` из `.json` не хуже предыдущего (см. `docs/PERF.md`)
- [ ] проверено и в ванильном UFO, и в Пиратках — рулсеты и наборы у них разные
- [ ] правки в `bin/common` / `bin/standard` перенесены в установку Пираток и озвучены
- [ ] грабли, на которые наступили, записаны в `docs/RAKES.md`
- [ ] `CHANGELOG.md` пополнен строкой на языке игрока
