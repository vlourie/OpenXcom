## 3. Ядро HD (`HdCanvas`, `HdSprites`, `HdWorkers`, `HdSmooth`, `HdTest`)

9 515 строк в `src/Engine/Hd*`. Форма правильная. Найдено одно нарушение инварианта и семь мест на починку.

**K-1. Инвариант `k = 1 IDENTICAL` в режиме 0 верен только для конфига, которым никто не играет.**
`src/Engine/Screen.cpp:112`: `_bpp = 32`, если `oxceHdScale > 1 || oxceHdPictures || oxceHdUi > 0`; `oxceHdPictures` по умолчанию `true`. `Map::createCanvas()` (`Map.cpp:275-287`) при `isLayered()` даёт `Canvas32` даже в режиме 0 при `k = 1`. Дальше:
- `Canvas32::doVapor` (`HdCanvas.cpp:1124-1148`): `r = min(255, r*tint.unused/255 + tint.r)` без возврата в палитру;
- `Canvas32::doFlash` (`1150-1167`): `255 - (255 - c)/4`, тогда как `Canvas8::flash` (`90-102`) делает `(pixel & 0xF0) + 1` — другой цвет по построению;
- `Map::hdTestFreeze` (`Map.cpp:830-837`) очищает `_vaporParticles` перед дампом — тест на IDENTICAL слеп ровно к тому пути, который расходится.

Починка: в режиме 0 либо всегда `Canvas8`, либо `Canvas32` с паром и вспышкой через LUT палитры (побайтно как `Canvas8`); заморозка должна оставлять детерминированный набор пара, а не пустой. Приёмка — дамп с паром и вспышкой на `k = 1` и `k = 4`.
