# XP-000541: ударения в текстах 46 тонов (до звука)

Акценторы, которые работали в `D:/VoiceFactory/runtime/venv` (CPU): **silero-stress 1.4** и **RUAccent 1.5.8.3** (`turbo3.1`, со словарём). Оба прогнаны на всех текстах; односложные слова и «ё» (всегда ударная) при сравнении не считались. Полная таблица: `art/sfx/voicepack/xp541_text.tsv` (в git не идёт, `art/` игнорируется), решения: `art/sfx/voicepack/xp541_stress_manual.tsv`.

Объём: 718 строк (46 опорных текстов + 672 реплики 16 базовых голосов), 685 разных текстов. Расхождение между акценторами: **75 строк** (67 разных текстов, 48 пар слов). Омографы из списка HARD (`voice_text_check.py`): 4 слова, 6 строк. Знак «?»: 132 строки (28 из 46 опорных), «!»: 60. Внутри каждого опорного текста есть запятая или точка — паузы на знаках нужны везде.

## Кто прав при расхождении (правила применены в столбце `ударения_итог`)

- **Верить silero:** понял+а (не п+оняла), п+осле, п+отом (наречие, кроме одной строки «Потом.» V004 34), связ+и, как+ая, д+аже, т+олько, бег+у, недалек+о/далек+о, гот+ов, душ+а, держ+ите, дв+ери (от двери), гл+аза, больш+ая, теб+я, хот+я, л+адно, с+амое, сейч+ас, поп+ался, л+ужу, н+оги (под ноги), задан+а, и «это» с ударением на «э».
- **Верить RUAccent:** р+уки (Руки чистые), гер+ой, ба-б+ах, с+орок, ей-б+огу, обо мне без знака, д+ома (как дома), рог+а, по-дерев+енски, по-хор+ошему, пок+а (Скажи «пока»), пр+обил (час пробил), ст+ены, кое-чт+о и ког+о-нибудь с одним ударением.
- **Ошибаются оба:** «потом» как «пот+ом» в «Там потом взорвётся» (опорный V166 и реплика V004) и «С совестью я потом разберусь» → надо п+отом.

## Решения руками

| Слово / строка | Что выдали | Предложение |
|---|---|---|
| потом (наречие, везде) | пот+ом (RUAccent в 4 строках; оба в двух) | п+отом |
| не было (V006 38) | б+ыло | н+е было (правило `reading_rules.csv`) |
| из-за (V021 37) | +Из-з+а / +Из-за | из-з+а |
| Дорога в ад? (V024 20) | Дор+ога | оставить; существительное, не «дорог+а» |
| мою (V004 26, V006 32, V013 28) | мо+ю | оставить: притяжательное «мою́» |
| пошли (V013 22) | пошл+и | оставить: «пошли́!» |
| запах (V010 22) | з+апах | оставить: «за́пах» |
| Все. (V010 16) | оба: Всё. | решить смыслом: «Глаза на месте. Все.» = все глаза; ё не ставить, ударения нет |

Ложные «ё» (RUAccent добавил там, где её быть не должно): далеко → далёко (4 строки, V201, V202, V018, V019), недалеко, лет → лёт, самое → самоё, все → всё. В текстах «ё» ставить не нужно, **настоящих пропусков «ё» нет**.

Остальные 1000 с лишним слов оба акцентора поставили одинаково, выборочная проверка по русским нормам ошибок не нашла.
