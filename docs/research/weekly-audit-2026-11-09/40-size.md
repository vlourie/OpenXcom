## 3. Сжатие арта (`a9_png.py`, `a9b_png.py`, `b1_hdp.py`)

Выборка из стейджа (seed 20261109): 300 PNG `hd/UI` (карточки, без кукол), 100 кукол (`*__N__*.png`), 300 `hd/TERRAIN`.
«opt» = ImageMagick `-strip`, zlib 9, адаптивный фильтр (аналог `optimize=True`; настоящих zopfli/oxipng нет — их выигрыш **не замерено**,
по опыту ещё несколько процентов). «optrgb» = opt + RGB вместо RGBA там, где вся альфа 255. «optz» = opt + обнулить RGB у пикселей с альфой 0.
WebP lossless: `-define webp:lossless=true method=4 quality=100` (method 6 дал бы ещё 1–3 %, не мерил); «exact» — сохраняет RGB под нулевой альфой,
«обычный» — как делает libwebp по умолчанию (отбрасывает его). Пикселевая сверка с оригиналом (AE) — 0 расхождений во всех 700 файлах.
Проценты — от выборки, пересчёт на группу — линейный.

| Группа (всего в стейдже) | Выборка, МиБ | opt | optrgb | optz | WebP exact | WebP обычный |
|---|---:|---:|---:|---:|---:|---:|
| UI-карточки, 2 021 файл, 1 774 МиБ | 260,6 | −2,9 % (−51 МиБ) | −10,0 % (**−178** МиБ) | −2,9 % | −32,5 % (**−576**) | −32,5 % (−576) |
| UI-куклы, 3 731 файл, 593 МиБ | 16,9 | −5,0 % (−29) | −5,0 % | **−79,4 % (−471)** | −39,4 % (−234) | −87,6 % (−519) |
| TERRAIN, 33 991 файл, 695 МиБ | 6,2 | −0,2 % (−1) | −0,2 % | **−36,1 % (−251)** | −30,2 % (−210) | −56,8 % (−394) |
| Итого по трём группам | | −82 МиБ | −209 МиБ | −900 МиБ (опт.+RGB карточек+zero) | −1 020 МиБ | −1 489 МиБ |

* Типы цвета в выборке: карточки — RGBA 152 (из них 148 с полностью непрозрачной альфой), RGB 89, палитра 59; куклы и TERRAIN — все RGBA.
* **Текстовых чанков (tEXt/iTXt/…) нет ни в одном из 700 файлов** — выигрыша от `-strip` нет.
* У кукол и террейна главный вес — RGB в полностью прозрачных пикселях (пример: `ubergal__9__swash_sash.png` 217 804 → 13 884 байта).
  Движок масштабирует кадры в предумноженной альфе (`HdSprites.cpp:1266`), поэтому этот цвет не виден; но побайтный RGBA после декодера изменится,
  значит нужна сверка Ctrl+F8 / `hdtest_compare.py` при `k=1` и `k=4`, и не проверено, нет ли кода, читающего RGB при альфе 0.
* Что даст WebP сверх PNG-обнуления: куклы −519 против −471, TERRAIN −394 против −251, карточки −576 против −178 → +589 МиБ.
  Скорость декодирования WebP под `HdWorkers` не мерил.
* Прочие группы (BIGOBS 45, FX 19, BASEBITS 24, PILOT — OGG) в этот раз не пересэмплированы; по 27.10 WebP даёт им −31…−41 %.
* **Паки `.hdp`**: 700 штук, 327,6 МиБ; внутри — сами PNG (168 653 кадра: палитровых 161 844, RGBA 6 809), то есть уже сжаты deflate;

## 6. Манифест при каждой проверке (`d1_manifest.py`, `d2_delta.py`)

Манифест 2026.11.09: **21 636 732 байта (20,63 МиБ)**, 123 063 записи `{"path","size","sha256","component"}`, подписан отдельным `.sig`.
Caddy теперь сжимает манифесты и заметки gzip (`portal/deploy/Caddyfile:12–18`), на сети это **gzip ≈ 5,43 МиБ** (`gzip -9`; brotli-9 5,14).
`Updater.CheckAsync` (`Updater.cs:80–83`) → `RepoClient.GetLatestAsync` берёт манифест целиком при каждой проверке; кэша по `ManifestSha256`
из указателя я не нашёл.

| Вариант (оценка по содержимому, один выпуск) | raw, МиБ | gzip-9 | brotli-9 | xz |
|---|---:|---:|---:|---:|
| сейчас | 20,63 | 5,60 | 5,27 | 4,52 |
| sha256 в base64 вместо hex | 18,16 | 4,82 | 4,43 | 4,47 |
| массивы `[path,size,sha,comp]` вместо объектов | 16,52 | 5,43 | 5,18 | 4,43 |
| массивы + base64 + компонент индексом | 12,79 | 4,76 | 4,40 | 4,29 |
| сгруппировано по папке и компоненту + base64 | 7,96 | **4,61** | 4,27 | 4,22 |

* Нижняя граница — случайные sha256: 114 411 уникальных × 32 байта = **3,49 МиБ** (из 123 063 записей 8 652 — повторы содержимого). Пути сжимаются
  с 6,0 до 0,37 МиБ (gzip), то есть пути не проблема; главное — хэши (hex занимает 7,5 МиБ сырых).
* Любое переформатирование даёт на сети лишь −0,8…−1,0 МиБ (−15…−18 %) и ломает старые лаунчеры (формат подписан, `schema: 2`) — выгода маленькая.
* **Дельта**: между 11.08 и 11.09 отличаются 2 записи (0,0003 МиБ), между 11.07 и 11.09 — 391 запись (0,06 МиБ) против 5,4 МиБ целого.
* Запуск лаунчера без нового выпуска: 5,4 МиБ только чтобы узнать, что ничего не нового (указатель весит ~1 КиБ).
