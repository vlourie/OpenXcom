# Перебор настроек map_paint --mode regions (2026-09-25, до 15:00)

Цель — найти одно сочетание настроек для рисования карты целиком. Судил по листам
«оригинал | прежний пак | прогон» в полный рост и по листу уровня карты (R-066),
метрики — только для отсева брака. Все прогоны — `art/maps/paint/sweep/`, журнал `sweep.log`.

## Профиль

```
--mode regions --g-context 8 --region 128,128 --use-done 0 --solo --hints <файл>
--edge-blur 0.5 --cfg 8 --tone 1.0
--canny 0.1 --tile 0.45 --strength 0.75            # предметы: природа, камень
--canny 0.2 --tile 0.5  --strength 0.7             # предметы: город, база пришельцев
--field g=16,tile=0.6,canny=0.2,strength=0.65,cfg=6.5,use_done=1   # поля полов и стен
--variants 3 --variant-sets <природная земля>       # R-039
```
плюс основа `sweep.sh`: `--refine 0 --tile-blur 0 --soft-edge --tile-min 6 --steps 20`.

Почему так:
- участок 128×128 при g=8 — это 1024 px, родной размер SDXL: резче g=16 и втрое быстрее;
- предметы — свободно: чёткая естественная фактура; содержание держат подсказки на кадр (R-007);
- `--solo` — у каждого предмета свой участок и своя подсказка;
- поля — строго: со свободными настройками стыки плиток рисуются рамками (R-079);
- `--edge-blur 0.5` убирает лесенку на кромке, 1.2 уже съедает тонкие листья;
- `--tone 1.0` возвращает средний цвет оригинала полностью (0.7 оставлял дверь BARN серой).

## Что исправлено в map_paint по ходу перебора

1. **Тема сцены не делилась на «поверхности | предметы»** (R-016, четвёртый повтор).
   У DESERT05 черта стояла без пробела, у JUNGLE04, CULTAFARM01, CARGO00 и
   CULTASOLHUGE01 её не было вовсе. Поле и участки solo получали весь список предметов:
   на каждой клетке песка веточка, ящик вместо тюка. Разбор теперь делит по голой черте,
   а `tools/test_map_scenes.py` требует черту у каждой темы.
2. **Обломки рисовались с подсказкой целого предмета** — разбитый кактус выходил целым,
   горелое пятно URBAN 91 — красной доской. Теперь у обломков и двери своя подсказка,
   а без неё к подсказке добавляется «broken wrecked remains».
3. **Предмет на полу попадал в чужой участок** (DESERT 7 — опунция — в участок змеи 5
   и выходил змеёй). В solo пол со своей подсказкой рисуется в своём участке.
4. В лог пишется подсказка каждого поля и участка — без этого (1) было не найти.

## Не решено

- **Деревья с плотной кроной** (JUNGLE 4–7). Свободные настройки дают куст или папоротник,
  строгие (canny 0.3, tile 0.6) — ком пикселей под лаком (R-004, R-066), размытие входа
  (tile-blur 0.5) — размытый ком. Середина (canny 0.2, tile 0.55, strength 0.7) спасает
  только дерево 3 со стволом. Прежний пак (LoRA 24.09 с альфой по силуэту) лучше всех —
  такие кадры брать из него.
- Фазы анимации рисуются порознь (R-071).
- Настройки задаются на прогон, а не на вид кадра: деревьям нужен свой профиль.
