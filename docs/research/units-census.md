# Перепись графики юнитов боя

Дата: 2026-10-03. Скрипт: `tools/unit_census.py` (py -3.13, ~22 с, только чтение игры).
Данные: `census/units/*.tsv`, сводка `census/units/summary.json`.
Назначение: основа ТЗ на генерацию HD-юнитов — что рисовать, сколько, что выводится из чего.

Повторить:

```
PYTHONIOENCODING=utf-8 py -3.13 tools/unit_census.py            # обе игры, сверка HD по 6 кадров на пак
PYTHONIOENCODING=utf-8 py -3.13 tools/unit_census.py --verify-hd -1   # сверить все кадры паков
```

## Как читается (чтобы числам можно было верить)

| Что | Как в скрипте | Откуда правило |
|---|---|---|
| моды и порядок | `options.cfg` установки + `metadata.yml`: xcom1, piratez, XPZ_EX_RU-patch, piratezRusNames, piratezCitiesLore, UFOextender_Psionic_Line_Of_Fire, piratez_tank_turret, intro_voice, hd | ModInfo / Mod::loadAll |
| рулсеты | загрузчик Tolerant из `tools/rul_map.py` (повторный якорь yaml-cpp) | R-046 |
| PCK | кадры подряд, из TAB только число кадров | R-075, SurfaceSet::loadPck |
| PNG | индексы, первый индекс с альфой 0 = 0 (FixTransparent), индекс 0 прозрачен | R-043 |
| extraSprites | `files {номер: путь}`, subX/subY режут картинку построчно, путь на `/` — папка в естественном порядке, поздний мод перекрывает файл по пути | Mod::loadExtraSprite |
| номера общих наборов | HANDOB, FLOOROB, BIGOBS: номер не меньше числа ванильных кадров получает смещение мода 1000 × накопленный reservedSpace (piratez 1000, RU-patch 7000, tank_turret 15000, hd 17000); листы юнитов без смещения | R-082, Mod::getOffset |
| HD-пак | `hd/<лист>/pack.hdp` («OXHDPCK1», таблица index/offset/size), по всем модам установки; `settings.txt` — модель | HdSprites |
| сверка HD | альфа HD-кадра, сжатая к 32×40, против маски классики (IoU), по 6 кадров на пак | — |
| семейства | только кадры С ТЕМ ЖЕ НОМЕРОМ: побайтно, по маске, по функции цвета A→B одной на весь лист | R-049, R-136, R-166 |

Проверки здравости, которые прошли:
- непустых кадров = уникальных + выводимых копией: 166 837 = 96 509 + 70 328;
- рисовать = уникальных − выводимых перекраской: 71 726 = 96 509 − 24 783;
- у всех 969 броней лист найден, кроме `STR_UNARMORED_HUMAN` (лист не задан вовсе);
- трупов без кадра ноль, кукол инвентаря без файла ноль;
- IoU HD против классики 0,99–1,00 почти у всех; ниже — только стелс и полупрозрачные (PIR_493 0,77, PIR_46 0,82, DEM_8 0,89), сдвига силуэта нет.

## Семейства — главный рычаг экономии

## Чего перепись не знает

- Видимость, стелс и прочие поля боя (кроме movementType) — не читались.
- Предметы в руке (HANDOB) перечислены, но не сгруппированы в семейства.
- Семейства ищутся только между кадрами с одинаковым номером: сдвиг раскладки листа на кадр связь скроет.
- Зеркальные пары внутри листа (направления 0↔6, 1↔5, 2↔4 по `Pathfinding::dir_x/dir_y`; 3 и 7 — сами себе)
  здесь не искались — кандидаты в `units-coverage.md`; у юнитов свет нарисован с одной стороны, поэтому побайтных зеркал почти не будет (R-054).
