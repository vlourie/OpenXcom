Дата: 2026-10-27. Статус: **план, ждёт решения Vitali**. Пока ничего не снято и не выложено.

## 1. Что нужно для страницы

- 15–20 снимков 1920×1080. Всё на английском: язык игры `en-US`, язык лаунчера `en`.

## 3. Клипы базы

Сейчас записать ролик из игры нечем. Стенд снимает отдельные кадры, а у базы часы экрана идут по `SDL_GetTicks`
(`src/Basescape/BaseView.cpp:679`). Кадры через `shot` выходят с неровным шагом, и видео дёргается.

**Предлагаю:** команда стенда `record <папка> <кадров> <fps>`. Пока она идёт, часы экрана базы шагают ровно
на 1000/fps за кадр, и каждый кадр пишется в PNG. Потом `ffmpeg` склеивает их в mp4 (ffmpeg уже стоит:
`C:\ProgramData\chocolatey\bin\ffmpeg.exe`).

- Это правка движка через editq. Работает только под `OXCE_HD_CONTROL`, игрокам не видна.
- Дамп режима 0 при k=1 должен остаться IDENTICAL.
- Альтернатива: снимать видимое окно через `ffmpeg gdigrab`. Тогда игра на несколько минут займёт экран.

Видео mod.io не хранит: в разделе media принимаются картинки и ссылки на YouTube и Sketchfab.
Значит, клипы надо залить на YouTube (канал Vitali), а на mod.io положить ссылки.
Короткие GIF можно добавить как картинки.

Клипы:

- A — полный круг дня и ночи;
- B — экипаж: лаборатория, мастерская, коридоры;
- C — вода, трубы, приступы построек.

Ангар с ремонтом (`OXCE_HD_HANGAR_LIFE`) — только если Vitali его одобрит.

## 4. Автовыкладка

1. **Один раз, руками Vitali:**
   - аккаунт mod.io;
   - страница мода в игре OpenXcom (условия mod.io принимает он);
   - OAuth-токен с правом записи: https://mod.io/me/access → OAuth 2.

   Токен кладётся в `portal.env` станции, не в репозиторий.
2. **Скрипт `tools/modio_publish.py`** — `POST /games/51/mods/<id>/files`:
   - архив лаунчера, `version`, `changelog` из `next.en.txt`;
   - `active=true`, `filehash` md5;
   - больше 100 МБ — multipart.

   Вызывается шагом после выпуска `launcher-stable` и проверяет, что файл с этой версией ещё не выложен.
   Медиа (снимки, ссылки на YouTube) обновляет тот же скрипт по команде, не на каждый выпуск.
3. **Риск.** mod.io проверяет загрузки антивирусом. Модераторы игры могут не принять программу вместо мода.
   До первой выкладки прочитать правила игры 51. Если сомнительно — написать модераторам.

## 5. Порядок

1. Снимки лаунчера и игры. Движок не меняется, можно начинать сразу.
2. Команда `record` → клипы A–C → выбор Vitali.
3. `modio_publish.py`. Пробная выкладка — после того как Vitali создаст страницу и даст токен.

Источник по API: https://docs.mod.io/restapi/docs/add-modfile
