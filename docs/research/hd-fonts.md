# Шрифты HD-интерфейса: наборы и переключение

Дата: 2026-09-21. Кто спрашивал: оригинальный шрифт игры округлее, наш Roboto слишком ровный —
нужны разные гарнитуры с переключением.

## Как устроено в движке

| Что | Где |
|---|---|
| опция | `oxceHdUiFont`: 0 — шрифт игры со сглаживанием, 1..N — наборы TrueType |
| набор из мода | `hd/UI/FontBig.ttf` + `FontSmall.ttf` (как было) — это набор 1, «Default» |
| остальные наборы | `hd/UI/fonts/<Имя>-Big.ttf` и `<Имя>-Small.ttf`; одиночный `<Имя>.ttf` идёт на оба |
| запасная гарнитура | `hd/UI/FontFallback.ttf` (DejaVu) — знаки, которых нет в основной |
| поиск наборов | `HdUi::scanFontSets` (HdUiDraw.cpp), раз при загрузке модов |
| применение | `HdUi::applyFontOption` — в `frameDone` и сразу при клике в списке опций |
| имя в списке опций | `HdFont::familyName` — как гарнитура зовёт себя сама (`name` id 16, затем 1) |

Порядок наборов — «Default», дальше по алфавиту имён файлов, поэтому номера не пляшут между
запусками. Новый шрифт добавляется без единой строки кода: положить пару файлов в `hd/UI/fonts`.

## Наборы, которые положены в мод

Все под OFL, все с кириллицей, лицензия лежит рядом файлом `<Имя>-OFL.txt`.

| № | Как зовёт себя | Характер |
|---|---|---|
| 1 | Default (Roboto) | нейтральный гротеск, был единственным |
| 2 | Comfortaa | самый круглый, мягкий геометрический |
| 3 | Exo 2 | техно со скруглениями, ближе всего к оригиналу X-COM |
| 4 | Jura | узкий техно, влезает в тесные колонки |
| 5 | Rounded Mplus 1c | круглые окончания штрихов |
| 6 | Play | техно-гротеск, плотный |
| 7 | Rubik | гротеск со скруглёнными углами |
| 8 | Unbounded | широкий геометрический, круглые О — по ширине ближе всех к оригиналу |

Лист сравнения с классическим шрифтом — `docs/research/hd-fonts.png`; собирается командой
`py -3 tools\hdart\fetch_fonts.py --sheet docs\research\hd-fonts.png`.

## Ширина против классического шрифта

Замер по правилу из граблей R-021: классический шрифт по чернильной коробке из `FontBig.png`
(заглавная 13 px, строка «AIMED SHOT 47% BRAVERY» — 225 px), TTF по advance при той же высоте
заглавной. Движок ставит TTF на 0,78 классической высоты, поэтому в игре строка выходит
примерно на четверть уже, чем в таблице.

| Набор | Латиница | К классике | Кириллица |
|---|---|---|---|
| Default (Roboto) | 228 px | ×1,01 | 256 px |
| Rounded Mplus 1c | 232 px | ×1,03 | 258 px |
| Exo 2 | 237 px | ×1,05 | 262 px |
| Comfortaa | 238 px | ×1,06 | 265 px |
| Rubik | 249 px | ×1,11 | 280 px |
| Jura | 254 px | ×1,13 | 258 px |
| Play | 262 px | ×1,16 | 286 px |
| Unbounded | 297 px | ×1,32 | 327 px |

Unbounded шире Roboto на треть: по характеру он ближе всех к оригиналу, но и первым упрётся
в тесные колонки (меню действий, списки с числами). Укладка сама сжимает строку по колонке,
поэтому смотреть надо не на «влезло — не влезло», а на то, не стала ли строка заметно уже соседних.

## Где сидит строка: заглавные сверху, хвосты снизу

Базовая линия считается в `baselineWithTails` (HdUiDraw.cpp): заглавные центрируются в клетке,
но строка поднимается, если хвост гарнитуры не кончается внутри клетки. Глубина хвостов —
у самой гарнитуры (`HdFont::descent`, меряется при загрузке по `p q y g р у ф д`), а не у
конкретной строки: иначе строка с хвостами и строка без них сядут на разные линии и соседние
ячейки списка разъедутся.

Классический шрифт нарисован под свою клетку: у мелкого хвост «р» занимает ровно одну строку
ниже базовой линии из девяти, у крупного — три из шестнадцати. TTF при той же высоте заглавной
свисает вдвое глубже, а ячейка списка — это `Text` высотой ровно в клетку шрифта, и она же
обрезает. Сколько хвоста уходило за клетку до правки (мелкий шрифт, `k = 4`, экранные пиксели):

| Набор | Хвосты, % размера | За клеткой было | Стало |
|---|---|---|---|
| Default (Roboto) | 21 | 2,5 px | 0 |
| Comfortaa | 22 | 2,6 px | 0 |
| Exo 2 | 21 | 2,5 px | 0 |
| Jura | 24 | 3,0 px | 0 |
| Rounded Mplus 1c | 22 | 2,9 px | 0 |
| Play | 22 | 3,0 px | 0 |
| Rubik | 19 | 1,7 px | 0 |
| Unbounded | 15 | 0,9 px | 0 |

Строка в логе при загрузке шрифта — `capitals 61%, tails 15% of the size` — говорит то же самое
числом: чем глубже хвосты, тем выше поднимается строка в клетке.

## Откуда берутся файлы

`tools/hdart/fetch_fonts.py` качает шрифты из репозитория google/fonts, а дальше:

- переменный шрифт инстанцируется в вес 400 (Small) и 700 (Big). Это обязательный шаг:
  stb_truetype не применяет вариации и видит у переменного файла только начертание по
  умолчанию, поэтому жирный обязан быть отдельным файлом;
- набор подрезается до знаков, которые вообще встречаются в интерфейсе (латиница с
  расширениями, греческий, кириллица, типографика, валюты, стрелки, геометрия, масти) —
  Rounded M+ так худеет с 3,4 МБ до 260 КБ;
- покрытие проверяется по текстам игры и модов (`Language/en-*.yml`, `ru*.yml`) — это про
  грабли R-020: отсутствующий знак движок молча рисует вопросом. По всем восьми наборам из
  текстов не хватает только ♥ U+2665, его закрывает запасная гарнитура.

```
py -3 -m pip install fonttools brotli
py -3 tools\hdart\fetch_fonts.py                                  # в user\mods\hd
py -3 tools\hdart\fetch_fonts.py --dest <мод в установке игры>     # то же в Пиратки
py -3 tools\hdart\fetch_fonts.py --check                          # только покрытие
```

## Чего эти шрифты не умеют

Ни один из восьми (и запасная гарнитура тоже) не покрывает CJK. На экране выбора языка
названия «日本語», «한국어», «中文» рисуются вопросами, в логе три строки `no glyph`. Это было
и до наборов — Roboto их тоже не знает; классический слой берёт их из `FontBig_jp.png`.
Чинится либо запасной гарнитурой с CJK (Noto Sans CJK — это десятки мегабайт), либо тем,
чтобы названия языков на этом экране рисовать классическим шрифтом.
