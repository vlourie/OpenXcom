### 1. Таблица символов занимает 18,8 % exe и не нужна игроку
- Тип: размер
- Серьёзность: средняя
- Где: `build-release/bin/openxcom.exe` (61 976 584 байт); флаги линковки `src/CMakeLists.txt:681,687` (нет `-s`/`--strip-all`)

- Выигрыш: до 11,67 МБ на диске (18,8 % exe), в архиве обновления около 1,3 МБ по zlib. Считал по размеру секций, не по пересборке.
