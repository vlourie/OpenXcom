## Проект

Флаг `OXCE_AI_HIVE_CONTACT=1` поверх `OXCE_AI_HIVE=2`, отдельная копия дерева `cc/tree`. Выключен — поведение HH.

На плане стороны, до задач подразделений:
- **ENGAGE** — живой боец видит контакт сейчас. Видящий приказа не получает, бой решает его `think()`. Невидящие идут на узлы с линией.
- **REINFORCE** — только из подразделений с задачей SEARCH по сектору, никто не видит врага, минимум 2 вооружённых с патронами, есть узел. Число: не больше 2 и не больше половины свободных, по одному на контакт. Охрану не снимаем. Срок 3 хода, приказ бойцу обновляется каждый ход.
- **MAINTAIN** — остальные. Контакт как цель им не выдаётся. Пересмотр только если контакт, видимый в этом ходу, ближе `HOLD_EXIT_RADIUS` от якоря; тогда ENGAGE с причиной `threat_near`.
- Отмена REINFORCE: контакт не виден в этом ходу и другого нет, нет узла ни у кого, срок вышел, 2 хода без сближения и без выстрелов, подразделение само увидело врага (→ ENGAGE). После отмены без единой атаки — 3 хода отдыха от назначений.
- Устаревшие контакты (`LAST_KNOWN`, `INFERRED`) никого не посылают.
- Механика `STAGE_RALLY` и принудительный HOLD не используются: у охраны остаются прежние выходы `not_useful` и `term_over`, но ведут они на обход сектора.
- Состояние ролей пишется в сейв (запись `R`). Журнал: `[HIVECC] CONTACT → DECISION → ASSIGN → ORDER → EXEC → FEEDBACK`.
