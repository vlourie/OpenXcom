# AI FORGE WP1 — план запусков

Записан до первого запуска, после запуска не меняется. Основание: GO Vitali 06.11. Бюджет: не больше 8 новых коротких запусков суммарно, включая контроли и повторы. Счётчик ведёт `AIForgeReplayRunner.py` в `ledger.tsv`, девятый запуск он откажется начинать.

## Условия всех запусков

| Что | Значение |
|---|---|
| Машина | rabota, задача `oxce_cmrun`, по одному бою за раз |
| Лимит ходов | 60, как у архивного D0 |
| Сейв, сид | M3 s1: `strim.sav`, 2015001. L8 s1: `NoCodexCatZ.sav`, 2032001 |
| Часы | виртуальные (`OXCE_AI_FAST=1`) |
| Флаги | те же, что у D0 (`COMMON_D0`), сверх них только `OXCE_AI_FORGE*` |
| Exe | FG: D0 (`07680cadb` + al + al3) + монитор только для чтения |
| Эталон | архив `res_sfF.zip`, `sfF_D_M3_s1`, `sfF_D_L8_s1`, только при совпадении отпечатков |

## Таблица

| № | Плечо | Сценарий | Что проверяет |
|---|---|---|---|
| P1 | SHADOW | L8 s1 | дымовой: монитор пишет, бой идёт, журнал разбирается. Самый короткий бой из двух |
| P2 | SHADOW | L8 s1 | резерв: только после одной правки по итогам P1 |
| R1 | OFF | M3 s1 | флаг не задан: совпадает с архивным D0, рукопашная и повторные действия |
| R2 | SHADOW | M3 s1 | монитор включён: действия и RNG те же, что у R1 |
| R3 | REPLAY | M3 s1 | повтор R2 до предела: события и отпечатки те же |
| R4 | OFF | L8 s1 | совпадает с архивным D0, псионика |
| R5 | SHADOW | L8 s1 | действия и RNG те же, что у R4 |
| R6 | REPLAY до N | L8 s1 | дойти до события N после первого пси, записать отпечаток, выйти; всё до N совпадает с R5 |

Перед R1 билд замораживается (`FROZEN.txt`); R1–R6 идут только на замороженном exe, runner это проверяет. Если после заморозки понадобится новый exe, все шесть проверок пришлось бы повторить, а бюджета на это нет: в таком случае STOP с отчётом, что осталось непроверенным.

Событие N для R6 берётся из R5: отпечаток `fp at=decide` первого решения после первого пси-действия врага.

## Что считается результатом

Сверка идёт не по строкам журнала, а по цепочке событий и отпечаткам реального состояния. При первом расхождении runner называет событие и раздел отпечатка; дальше STOP, без подгонки.

Если на L8 пси не будет или воспроизведения нет: блокер записывается. Резерв M6 s1 разрешён только как замена технической проверки и покрытие псионики не подтверждает; для него отдельного запуска в таблице нет, он занял бы место P2.

Не меняются: боевая политика, результаты `think()`, RNG, выбор активного юнита, порядок активаций, спавн, правила, формат сейва. Обучения нет. WP2–WP4 не начинаются.
