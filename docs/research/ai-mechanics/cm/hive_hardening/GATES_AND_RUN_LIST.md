## Условия

| Условие | Проверка |
|---|---|
| OFF = D0 | ход решений №1 совпадает с `scpa_D_M6_s1` |
| shadow не влияет | ход решений №2 совпадает с №1 |
| повтор | ход решений №4 совпадает с №3 |
| организация после спавна | `[HIVEINIT] origin=spawn` раньше первого решения любого бойца, на ходу игрока |
| нет двойных назначений | каждый боец в одном подразделении, командир среди своих |
| нет повторов невыполнимого | ни одного BLOCKED того же бойца на ту же цель при том же условии; память блокировок проверяется кодом и журналом |
| нет бесконечного HOLD | у каждого HOLD цель, причина, срок, выход; подряд без пересмотра не больше срока |
| два подразделения | минимум два подразделения с разными задачами, бойцы реально ходят |
| преемник | новый командир сохраняет задачу подразделения |
| сохранение и загрузка | `[HIVELOAD] parsed=1 same=1`, `origin=restored`, тот же hash, нет `origin=spawn` после загрузки |
| старый сейв | `origin=load_no_hive`, организация создана заново законно |
| FAIR | контакт берётся только из видимого живыми бойцами стороны |
| TU, RNG | в `HiveCommand.cpp` нет `RNG::` и записи в юниты, повтор IDENTICAL |
| стабильность | ни одного падения |

Вне проверки: старый дефект сейва посреди хода ИИ (задачей запрещено чинить), боевая эффективность (по условиям этапа не оценивается).
