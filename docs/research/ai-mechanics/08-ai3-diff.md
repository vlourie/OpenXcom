# AI3 против оригинала OXCE: что меняет каждый флаг

Фаза 1 программы `PLAN.md`. Источники: список `AI3_PROFILE` в игре (`src/Battlescape/AiProbe.cpp:246`), профиль
стенда (`census/ai4_2026-10-14/station/st/run_ai4st.py`, `FLAGS`), комментарии у кода в `src_ai4`, итог AI2
(`census/ai2h_2026-10-07/AI2_FINAL_REPORT.md`). Где флаг читается — `census/ai4_2026-10-14/scripts/ai_flags_doc.py`.

У игроков AI3 включён по умолчанию (опция `oxceAi3`). Флаги AI2/AI3 действуют на всех, кого ведёт `AIModule`:
врага, нейтралов и бота стенда. Остальные `OXCE_AI_*` в игре берут встроенное значение (выключены).

## 1. Решения врага (в игре включены)

| флаг | что меняется против оригинала |
|---|---|
| FAIR_KNOWLEDGE=1 | Решает по знанию стороны: скрытого бойца — по последней увиденной позиции, а не по настоящей. В оригинале враг, помнящий бойца (`turnsSinceSpotted ≤ intelligence`), целится и идёт в его настоящую клетку |
| ZERO_EFFECT=3 | Не тратит выстрел или удар, который не даст эффекта (урон не пробьёт, оглушение не возьмёт). В оригинале такой проверки нет |
| ZERO_HONEST=2 | Эта проверка читает только честное, без скрытой брони и щита цели (первая версия ZERO_EFFECT читала их — исправлено в AI2, блок A2H) |
| LEEROY_STALE_FIX=1 | Лирой не бежит на устаревшую цель |
| LEEROY_TU_FIX=1 | Лирой назначает удар, только если хватает ОВ сейчас (та же проверка, что у обычного ближнего боя) |
| SNIPER_AOE_EFFICACY=2 | Снайпер со взрывчаткой оценивает взрыв (своих в радиусе), как обычная граната |
| EFFICACY_NO_DIFF=1 | Бонус сложности больше не перекрывает штраф за своих в радиусе взрыва |
| RESERVE_AFFORDABLE=2 | Не держит резерв ОВ, который юнит всё равно не может оплатить |
| HYPO_LOS=1 | Линия огня с клетки, куда юнит только собирается встать, считается от его глаза на той клетке, а не от нынешней точки |
| MELEE_FIREPOINT_APPROACH=1 | Юнит только с холодным оружием не ищет огневую точку стрелка, а подходит к цели |

## 2. Путь и патруль (в игре включены; по замыслу — тот же выбор быстрее, но два меняют поведение)

| флаг | что меняется |
|---|---|
| STALE_PATROL_NODE=1 | **Меняет патруль:** сохранённый с прошлого раза узел, до которого нет пути, выбрасывается и выбирается новый (в оригинале юнит мог «держаться» недостижимого узла) |
| BLOCKED_STEP=1 | **Меняет ходьбу:** шаг, на котором ходьбу остановил юнит, запоминается до конца хода юнита, и путь пересчитывается в обход (в оригинале — повтор того же шага) |
| PATROL_STUN_PREFIX=1 | Патрульный путь обрезается до части, после которой оглушение не доводит до потери сознания |
| AMBUSH_MEMO=1 | Поиск засады пропускает узлы, заведомо недостижимые для бойца (ответ тот же, быстрее) |
| ESCAPE_REACH_FIRST=1 | Побег отбрасывает недостижимые клетки до трассировки линий огня (тот же выбор, быстрее) |
| STALE_EXACT=1 | Быстрый ответ на проверку достижимости сохранённого узла (вместе с STALE_PATROL_NODE) |
| LIGHTSKIP=1 | Без пересчёта света на шаге юнита, который сам не светит |
| WALKFOV_SKIP=1 | Только для бота стенда: пропуск пересчёта обзора для экрана ОВ |
| BOT_SPECIAL=1, BOT_WP_MELEE=1 | Только бот игрока (стенд): пси и бластер — по честному знанию, начатый пуск бластера не перебивается рывком в рукопашную. Врага не касаются |

## 3. Только стенд (в игре нет)

| флаг | что делает |
|---|---|
| FAST | Не рисует кадры, без звука; решения и исход те же |
| LOADOUT_FIX | Бойцу в броне, в которой он не может двигаться, выдаёт годную броню со склада (как сделал бы игрок) |
| KEEP_DECIDE | Читает обвязка стенда; в игре не действует |
| WP_SAFE=4, WP_OWNK=200 | **Искажение стенда.** Враг с бластером (пуск по путевым точкам) перед пуском прогоняет полёт ракеты с разбросом и не стреляет, если в среднем взрыв вредит своим (свои — с весом 200 %). В игре (AI3) этого нет: враг с бластером на стенде осторожнее, чем у игроков |
| RECORD, RECORD_PATH, MEDIPROBE, BLAST_PROBE, FAIR_SAVECHECK | Только запись журнала; решений не меняют |

## Что из этого следует

- Честность врага уже в игре: FAIR_KNOWLEDGE и ZERO_HONEST убрали чтение скрытых позиций, брони и щита. Это рамка
  Vitali («не может знать, сколько у меня отнялось»): улучшения фазы 3 строятся поверх неё, не в обход.
- Ни один флаг AI3 не трогает ответный огонь и резерв ОВ в бою (RESERVE_AFFORDABLE только убирает невыполнимый резерв
  патруля). Рычаг П8 (`phase2-results.md`) — свободное место.
- Выводы стенда о врагах с бластером (МЕРКи, Гильдия) нельзя переносить на игру один к одному из-за WP_SAFE/WP_OWNK.
