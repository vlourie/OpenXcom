# P0 vs P1 — критерий вывода, зафиксирован до результатов (27.10, до основной серии)

- Сравнение: D0 (выпускной ИИ, BetterAI OFF) против D1 (тот же, BetterAI ON) на стенде AL + `OXCE_AI_RELEASE_BASE=1` + `patch_al3`
  (бот за игрока одинаков в обеих конфигурациях).
- 24 сценария `scen.tsv` × сиды {seed, seed+1} × {D0, D1} = 96 боёв. Сиды выбраны до запуска, перебора нет, дополнительных боёв нет.
- Единица анализа — сценарий (кластер): разность D1 − D0 по каждому сиду, затем среднее двух сидов → 24 парные разности.
- **Главная метрика (одна):** доля отряда игрока, выбывшая за бой, `(pdead + pout) / player`. Больше — враг сильнее.
- Правило вывода по главной метрике: 95 % доверительный интервал среднего парной разности (бутстрэп по 24 сценариям, 20 000
  повторов, зерно 1) целиком > 0 → **BETTER**; целиком < 0 → **WORSE**; иначе **INCONCLUSIVE**. Знаковый тест по 24 сценариям —
  дополнительно.
- Вспомогательные (на вывод не влияют, только описание и проверка на противоречие): урон по игроку `phplost`; доля потерь врага
  `(hdead + hout) / hostile`; исходы победа / поражение / ничья / удержание; атаки врага и полезные атаки (цель `aim` — боец игрока,
  потерявший здоровье или выбывший в тот же ход врага); убийства и оглушения врагом (`[AICASUALTY]` kfaction=1); использование
  ОВ врагом (ОВ на `aistart T` минус ОВ на `pstart T+1`, доля от доступных); пустые решения (`act=0`) и циклы (подряд одинаковые
  решения юнита за ход: from, tu, act, to); зависания, падения; время боя.
- Бой, не дошедший до итога (`[AIRESULT]` нет) — исключается парой (сценарий-сид целиком) и указывается отдельно; повторов нет.
