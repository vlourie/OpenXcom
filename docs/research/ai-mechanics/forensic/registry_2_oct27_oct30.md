Числа — только из источников в `docs/research/ai-mechanics/` (имена файлов даны в колонке «Источник»); кроме двух мест, помеченных
«мой пересчёт» (таблица `pv/results/pv_pairs.tsv` / `pv_battles.tsv` пересчитана мной скриптом, результат совпал с отчётом).
Класс доказанности назначен по методу, а не по вердикту автора. Шкала:

| класс | смысл |
|---|---|
| ДОКАЗАНО | сравнение с контролем, побайтное тождество или полный пересчёт по данным; вывод следует из метода в заявленных границах |
| ВЕРОЯТНО | метод разумный, но есть выборка/перенос/определение, которые вывод ослабляют |
| ПРЕДПОЛОЖЕНИЕ | вывод опирается на оценку, оговорку или на экстраполяцию за границы данных |
| ЗАГРЯЗНЕНО | измерено не тем ИИ/стендом/сценарием, который заявлен, либо дефект реализации/учёта искажает число |
| МАЛО ДАННЫХ | доверительный интервал содержит и «польза», и «вред»; либо n слишком мал для вывода |

Условные обозначения конфигураций (BASELINE_0B, §1–2): **P0/P1** — настоящий выпуск `openxcom_hd.exe` 2026.10.27-2 (BetterAI выкл./вкл.);
**U0** — upstream OXCE 8.7.1 (`441cae1b0`); **D0/D1** — DEV-стенд с `OXCE_AI_RELEASE_BASE=1` (D0 = P0 и D1 = P1 доказано на одном ходе врага);
**DH** — умолчание стенда без этой переменной; **DS** — «протокольный стенд» C1/C2/FF (12 флагов, O1–O4/O6 принудительно, O5 выкл.);
**DSE** — то же на exe серии C1. Все бои — «бот за игрока» (тот же движковый ИИ), у выпускного exe бота нет (REAL_AI_P0_VS_P1 §1).
