Hi Dioxine! Same checker again, this time on Piratez_Resources.rul. It's in very good shape: every file path resolves, every image is 8-bit, no frame index is out of range, no two Piratez files write the same frame, and every pedia image, event background, interface background, UFO sprite, sound and HANDOB frame referenced from the other rulesets exists. One real bug, one sleeping typo, one question. Line numbers are from the current release.

1) Underwater tracers missing for 32 weapons (Piratez_Resources.rul:9803)
UnderwaterProjectiles declares height 135, but Projectiles_DIO.png is 105x162 (54 bullet rows). The land entry right above it (line 9796) says 162. OXCE cuts the sheet by the declared size, so rows 45-53 are never loaded underwater, and the tracer is simply invisible (Map.cpp skips a missing frame without an error).
Affected: every item with bulletSprite 45-53, and none of them is landOnly. For example: RPG / RPG_ADV / RPG_SMART, BFG, Plasma Scorcher, Battle Plasma, Elite Heavy Plasma, Recoilless Rifle, Mega Cannon, Durandal, SSRL_2, Baby Nuke, UAC Rocket Launcher, MrShan Launcher, Spore Launcher, plus tank cannons and rockets. The 15 underwater deployments (STR_SEA_*, TLETH base assault) are where it shows.
Now:
  - type: UnderwaterProjectiles
    width: 105
    height: 135
Fix:
    height: 162

2) DEM_1.PCK (Piratez_Resources.rul:3056): height 680, but DEM_1.png is 512x720 and DEM_0/2/3 all say 720. The last row (frames 272-287: female torso dirs 5-7 and the flying legs) is dropped. It's invisible today, because DOOM_ARMOR_1 isn't a soldier armor and non-soldiers are always male. But it will crash with "Frame(s) missing" the day it goes on a soldier or learns to fly. Fix: height: 720.

3) Question: `music: GMTACTIC1` (9 deployments: ATRIUM, BANDIT_CAVES, LOKNAR_ALTAR, MANSION, MONSTER_HUNT_SHAMBLER, NIGHTOSHPHERE_DELOREAN, NIGHTOSHPHERE_HARVEST, RITUAL_CAVE, SPACE_FREIGHTER; and 2 events, JACKASS_EXPANSION_NORTH_ATLANTIC and START_LOCATION_NORTH_ATLANTIC). OXCE picks a random track whose name CONTAINS the given string. So GMTACTIC1 means any of GMTACTIC1, GMTACTIC10...GMTACTIC19: 11 tracks, and the one you probably meant plays 1 time in 11. If that's intended, fine. If you wanted that one track, give it a name that isn't a prefix of others (e.g. GMTACTICA.ogg + `- type: GMTACTICA`).
