# Переключение баз стрелками на экранах базы — план (19.10.2026)

Запрос игрока: на экранах склада, лаборатории, чёрного рынка, мастерской, тюрьмы, тренажёрки
и пси-школы переходить на тот же экран соседней базы одной кнопкой, а не «выйти → выбрать
базу → открыть экран». Плюс то же на клавиши ← →.

Механику не трогает: только навигация между экранами. Код не правился — ждёт «да» Vitali на объём.

## Что есть сейчас (по коду)

| Экран игрока | Класс | Откуда открывают |
|---|---|---|
| Склад | `StoresState` | `BaseInfoState` |
| Лаборатория | `ResearchState` | база, `GlobalResearchState`, всплывашка «новое исследование» |
| Мастерская | `ManufactureState` | база, `GlobalManufactureState`, «производство готово», `CannotReequipState` |
| Чёрный рынок (покупка) | `PurchaseState` | база, «новое для покупки», `CannotReequipState` (с родителем) |
| Продажа (по желанию) | `SellState` | база |
| Тюрьма | `ManageAlienContainmentState` | база, `GlobalAlienContainmentState`, **переполнение после боя** (`DebriefingState`, `GeoscapeState`) |
| Тренажёрка | `AllocateTrainingState` | база, `SoldiersState`, `TrainingState`, «обучение окончено» |
| Пси-школа | `AllocatePsiTrainingState` | то же |

- Ни на одном из этих экранов **нет имени базы** — после переключения игрок не увидит, где он.
  Имя базы нужно добавить (строкой под заголовком или в заголовок «Склады — Альфа»).
- Есть готовый образец кнопок `<<` `>>`: `SoldierInfoState` (листает бойцов).
- ← → сейчас заняты только в `TextEdit` (курсор) и на глобусе; на этих экранах свободны.
  Но у склада, рынка и продажи есть поле быстрого поиска — пока оно в фокусе, стрелки должны
  двигать курсор, а не базу.
- Под экраном лежит `BasescapeState` (а у склада ещё `BaseInfoState`) со своим `_base`:
  при возврате он покажет старую базу. Нужно передать им новую базу (`BasescapeState::setBase`
  уже есть; `BaseInfoState` — аналогично).

## Предлагаемое устройство

1. Общий помощник `src/Basescape/BaseSwitch.{h,cpp}`: найти соседнюю базу в нужную сторону по
   кругу (с фильтром), закрыть текущий экран и открыть такой же для новой базы, обновить базу
   у экранов под ним.
2. На каждом экране — две маленькие кнопки `<` `>` у заголовка (`TextButton`, HD-зеркало у них
   есть) и клавиши ← → (`Options::keyGeoLeft/keyGeoRight`, их можно переназначить).
   Кнопки видны, только если есть куда переключаться.
3. Фильтр баз: лаборатория — базы с лабораториями, мастерская — с мастерскими, тренажёрка —
   с тренажёркой, пси-школа — с пси-лабораторией, тюрьма — с тюрьмой того же типа; склад,
   рынок, продажа — все базы.
4. **Включать только там, где переход ничего не обходит**: с экрана базы, сведений о базе и
   общих списков. **Не включать** при вынужденных открытиях — переполнение тюрьмы после боя,
   «не могу перевооружить», всплывашки «готово/новое». Иначе можно уйти с базы, не разгрузив
   переполненную тюрьму.
5. Незакреплённые изменения (рынок, продажа, тюрьма — пока не нажат OK): переключение
   **не выполняется**, кнопки тусклые. Альтернатива — молча сбросить, но это потеря ввода.

## Проверка

- сборка без новых предупреждений; Ctrl+F8 на геоскейпе-базе, режим 0, `k = 1` и `k = 4` — IDENTICAL;
- ванильный UFO и Пиратки (у Пираток свои `interfaces` — проверить, что кнопки не налезают на
  заголовок и поле поиска);
- строка в `CHANGELOG.md` на языке игрока.
