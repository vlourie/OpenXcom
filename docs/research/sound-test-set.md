# Звук: как устроен сейчас и тестовый набор (шаги по персонажу, голоса RU/EN)

Составлено 2026-10-15. Всё про движок — по коду (файл:строка), про Пиратки — по
`.index/mod/Piratez/rul/values.tsv` и `census/sounds.tsv`. Общий план озвучки — `docs/AUDIO_ROADMAP.md`.

## Как сейчас

### Шаги

- Звук шага выбирает только **пол**: `UnitWalkBState::playMovementSound`
  (`src/Battlescape/UnitWalkBState.cpp:562`) берёт `footstepSound` клетки из MCD и играет
  `WALK_OFFSET + 2·тип` на фазе шага 3 и `+1` на фазе 7. От бойца, брони, пола (женский/мужской)
  звук не зависит никак: девушка босиком, киллбот и дог по металлу звучат одинаково.
- У Пираток 6 материалов (номера 24–35, все HQ ogg): металл, земля, «марсианский» грунт, вода,
  песок, снег — по **одному** звуку на шаг, без вариантов. Отсюда и «надоедает»: каждый второй
  шаг — тот же самый файл.
- `moveSound` брони или юнита заменяет шаги одним звуком на фазе 0 — так звучат машины и
  парящие (251 ссылка), у пехоты Пираток его нет.
- **Крюк для мода есть:** скрипт брони `selectMoveSoundUnit` (`ModScript.h:336`, параметры —
  `BattleUnit.cpp:7312`) получает юнит, фазу шага, звук брони, звук и смещение материала клетки и
  возвращает номер звука. Выбор шага по персонажу делается модом, без правки движка.

### Голоса бойцов

- Механизм в OXCE полный: `voiceSets` (4 категории — выбор бойца, начало хода, выбор оружия,
  «отстань»), раздача по типу бойца `voiceSetsMale` / `voiceSetsFemale`
  (`RuleSoldier.cpp:190`), выбор набора и реплики — `RNG::seedless`
  (`RuleSoldier.cpp:566`, `BattlescapeGame.cpp:3695`), то есть **боевой генератор не тратится**.
  Набор запоминается бойцу в сейве (`voiceSetID`), есть экран выбора голоса на базе
  (`SoldierVoiceState`).
- У Пираток **голосов нет совсем**: `enableUnitResponseSounds` не задан, `voiceSets` пусто.
- Частота по умолчанию — выбор 100 %, ход 100 %, оружие 100 %, «отстань» 20 %
  (`Mod.cpp:311`); меняется полем `unitResponseSoundsFrequency`.
- Голос играет на канале 4 и не перебивает сам себя: пока говорит, новая реплика пропускается.
- **Языка у звука нет.** Набор голосов не знает языка игры, рулсет от языка не зависит. Без
  движка выбор языка — только какой мод включён (или что поставил установщик).

## Тестовый набор

Всё генерируется локально и только через очередь видеокарты (`tools/gpuq.py`).

| Что | Чем | Скрипт |
|---|---|---|
| шаги: 5 классов обуви × 6 материалов × 8 кандидатов, в мод 4 лучших | Stable Audio 3 Small SFX | `tools/sfx/gen_steps_test.py` |
| доги: лай, рык, скулёж по 4 категориям | Stable Audio 3 Small SFX | там же |
| голоса: опорный голос персонажа по описанию | VoxCPM2 (режим design) | `tools/sfx/gen_voices_test.py` |
| реплики RU и EN тем же голосом, 2 дубля, лучший по whisper | Fish S2 Pro (модель интро) | там же |
| моды и страница прослушивания | ffmpeg, numpy | `tools/sfx/build_test_mods.py` |

Реплики, классы обуви и кому что достаётся — `tools/sfx/test_set.py`.

### Шаги по персонажу (мод `hd_test_steps`)

Классы: босиком, ботинки, каблуки, тяжёлая броня, лапы с когтями. Броне в тесте даётся
`moveSound` = начало банка её класса (так номер проходит смещение мода — в скрипте своих
номеров мода нет) и скрипт `selectMoveSoundUnit`:

- фазы 3 и 7 на полу с материалом 1–6 → `банк + (материал−1)·4 + вариант`;
- вариант = `(id·7 + 3x + 5y + фаза) mod 4` — от номера юнита и клетки, **без генератора**;
- материал 0 (удар и крик) и всё остальное — как в движке; фаза 0 — тишина (без скрипта
  `moveSound` сыграл бы на ней);
- не на ходу (полёт) — звук полёта движка на фазе 1, как в оригинале.

Брони теста — те, у которых своего `moveSound` нет (у ксенфорсера он есть — не тронут).

### Голоса (моды `hd_test_voices_ru` и `hd_test_voices_en`)

Персонажи: боцманша и кавайка (девушки основных типов), громила (мужчины тех же типов),
кошкодевочка (некомими), киллбот (робот, металлический фильтр после синтеза), доги (лай — звук,
не речь, общий для обоих языков). Тон — грубый пародийный юмор с долей аниме (решение 2026-09-26).

Типы наборов в двух модах одинаковые (`HD_VOICE_BOSUN` …), поэтому боец, получивший голос,
сохраняет его при смене языкового мода. Включать один из двух. Частота в тесте снижена:
выбор 70 %, ход 35 %, оружие 50 %, «отстань» 20 %.

### Чего тест не решает

- **Язык автоматически.** Нужен либо выбор мода установщиком по языку (как RU-патч), либо
  правка движка: путь к файлу звука с подстановкой языка. Решать Vitali.
- **Мод без движка снимается чисто?** Боец с `voiceSetID` набора, которого нет, — движок ищет
  набор с `error=false` (`BattleUnit.cpp:319`) и молча выдаёт новый; проверить на сейве.
- **Перекрытие брони Пираток** (путь A в AUDIO_ROADMAP.md): на весь гардероб это сотни записей,
  которые отвалятся при переименовании у Dioxine. Для теста — 16 броней. На выпуск — либо
  общий скрипт с тегом брони, либо слой `HdSound` (путь B).

### Переделка голосов по высоте (задание №624)

140–155 Гц и кошкодевочка 150–165 Гц — как громила (150). Описание «низкий прокуренный» VoxCPM2
понял как мужской, а опорный выбирался только по распознаванию.

- Полоса высоты у голоса — поле `f0` в `test_set.py`: женские 180–500 Гц, громила 60–130.
  Опорный — из кандидатов в полосе, дальше от границы (Fish уводит реплики ниже опорного);
  реплика — дубли до `VOICE_TAKES_MAX`, пока два не лягут в полосу и по длине.
- Пол прямо в описании, громила — «очень низкий глубокий бас».
- Итог: боцманша 233–248 Гц, кавайка 250–262, кошкодевочка 285–313, громила 102–109;
  вне полосы — только «Шшш!» и «Pfft!» (шипение без тона). 437 дублей за 37 мин, ошибок 0.
  Плохо распознаются 4 «мур»-реплики кошкодевочки — для whisper это не слова.
- Киллбот не переделывался (полосы нет): три «отстань» длиннее 2,2 с.

### Как включить

Моды лежат в `Пиратки/Dioxine_XPiratez/user/mods/` и выключены. Включить в игре: «Моды» →
`hd_test_steps` и **один** из `hd_test_voices_ru` / `hd_test_voices_en`. Пересобрать:
`tools/sfx/.venv-sa3/Scripts/python.exe tools/sfx/build_test_mods.py`.
