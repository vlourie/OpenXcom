# Обрушение: прочность стволов деревьев — варианты (27.10)

Вопрос Vitali 27.10: можно ли поднять стволам прочность. В игре ничего не менялось, ниже подсчёт по коду и данным.
Любой вариант — механика, только под опцией «Обрушение зданий» и по слову Vitali.

## Как ствол ломается сейчас (OXCE)

- У части карты нет запаса прочности. Одно попадание ломает её, если сила по местности не меньше брони MCD
  (`Tile::damage`, `power >= armor`). Повреждения не копятся.
- Пуля и удар: сила по местности = разброс от power/2 до 3·power/2, умноженный на ToTile
  (`TileEngine::hit`, `getRandomDamageForTile`, `TileDamageMethod 1`).
- Взрыв: сила луча в клетке × ToTile, без разброса (`TileEngine::explode`, `TileDamageMethod 2`).
  ToTile по умолчанию 0.5, у огня, дыма и оглушения 0.
- Стволы (части деревьев на z0, `cp16/tree_mcd.tsv`, 2906 частей): броня от 8 до 80, медиана 20.

## Что валит ствол сейчас

Доля стволов, которые ломает одно лучшее попадание. Для взрыва сила взята в центре, к краю она падает. Доля
считается при нынешней броне, при броне ×2 и ×3 (`scratchpad cp24/tile_power.py`).

| Оружие | Сила по местности | ×1 | ×2 | ×3 |
|---|---|---|---|---|
| пистолет (STR_PISTOL_CLIP) | 19 | 48 % | 16 % | 0 |
| винтовка (STR_RIFLE_CLIP) | 22 | 51 % | 25 % | 0 |
| ПП, пулемёт, бронебойная винтовка | 26–28 | 75 % | 27 % | 16 % |
| тяжёлый пулемёт (HMG) | 41 | 94 % | 51 % | 27 % |
| граната (STR_GRENADE) | 28 | 75 % | 27 % | 16 % |
| осколочная граната | 34 | 85 % | 48 % | 25 % |
| динамит, малая ракета | 62–64 | 97 % | 76 % | 51 % |
| ранцевый заряд, HE-заряд | 75 | 100 % | 88 % | 74 % |
| ракеты танка | 88 | 100 % | 94 % | 75 % |
| тяжёлая бензопила | 82 | 100 % | 94 % | 75 % |

Главная нереалистичность: каждый второй ствол валится одной пулей из пистолета.

## Варианты

1. **Пуля дерево не валит.** Попадание пулей, лучом или плазмой в ствол идёт против брони ×3. Взрывы, огонь и
   рубка ближним боем — как сейчас. Пистолет и винтовка стволы не валят, тяжёлый пулемёт валит каждый четвёртый,
   автопушка — три из четырёх. Взрывы не меняются.
2. **Крепкий ствол.** Броня ствола ×2 против всего. Граната валит каждый четвёртый ствол, а не три из четырёх;
   динамит и ракета — три из четырёх. Минус: лес почти неуязвим для гранат, а это главное средство в Пиратках.
3. **Сочетание (рекомендую).** Пули и лучи ×3, взрывы ×1.5, рубка и огонь ×1. Пуля дерево не валит. Граната в
   упор валит каждый второй ствол (было три из четырёх), динамит 94 %, ранцевый заряд 97 %. Бензопила и топор
   рубят, огонь жжёт.
4. **Прочность с запасом.** Попадания копятся: ствол падает, когда сумма достигла брони × N. Это самый
   реалистичный вариант, но в клетке нет места под счётчик. Нужно новое поле в сейве, а это загрузка сейва и
   риск. Не рекомендую.

## Как сделать (для вариантов 1–3)

- Проверка — в одном месте перед `Tile::damage`, только при включённой опции «Обрушение зданий». Опция выключена —
  игра как в ванили, побайтно.
- Ствол — запись MCD из списка стволов (части деревьев на z0 по переписи, около 130 записей). Тогда правило
  действует одинаково на всех картах, а не только на блоках таблицы обрушения.
- Чисел ГСЧ не прибавляется: множитель применяется к уже вычисленной силе.
- Стенд: те же сценарии деревьев до и после. Считаем, сколько деревьев свалила граната, ракета и очередь, и
  проверяем, что с выключенной опцией ничего не изменилось.
- Побочно: меньше поваленных деревьев — больше укрытий в лесу, и ИИ это тоже увидит.
