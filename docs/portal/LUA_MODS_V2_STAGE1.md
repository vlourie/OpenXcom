## Поведение, которое авторам надо знать

Всё это на странице автора.

- Поле ввода в фокусе модально, это штатное поведение игры: первый щелчок вне поля только снимает фокус, `onKey` молчит. Esc работает всегда.
- Обработчики геоскейпа пока только читают, поэтому экран из них не откроешь: запрос появится с событиями этапа 2. Игрок открывает экран через экран модов.
- Тег кампании объявляется в `extended: tags: GeoscapeGame:`.
- Ключ без перевода показывается как есть и в журнал не пишет.
- `not enough memory` у мода может быть бюджетом C-циклов: `pcall` снимает его за каждый вызов.
