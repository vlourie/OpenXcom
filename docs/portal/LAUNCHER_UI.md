# Лаунчер: ТЗ на интерфейс

Статус: **черновик на согласование** (2026-09-23). Скетч экранов — артефакт
«Лаунчер X-Piratez HD — скетч» (ссылка в конце). Что меняет механику обновлений — не здесь:
этот документ только про то, как лаунчер выглядит и что игрок в нём видит.

Опоры: ARCHITECTURE.md (устройство), EDITIONS.md §«Невидимый помощник» и §«Оформление»,
DECISIONS.md (Avalonia + NativeAOT, «размер важнее богатства UI»).

## 1. Что не так сейчас

Сейчас главное окно (`portal/src/Xp.Launcher/MainWindow.cs`) — это пульт отладки обновлятора:

| Что видно | Почему плохо |
|---|---|
| восемь кнопок одной строкой: Играть, Обновить, Проверить, Восстановить, Откатить, Лаунчер, Отчёты, Поддержать | равный вес у ежедневного «Играть» и у раз-в-год «Откатить»; игрок читает все восемь, чтобы найти одну |
| «Канал», «Установлено 1.2.3 (r-2026…)», «Доступно …» | id релиза и канал нужны разработчику, игроку — нет |
| журнал на главном экране | технический текст на первом плане, пугает при любой строке ERROR |
| путь к папке игры в поле ввода сверху | задаётся один раз, а занимает первую строку навсегда |
| статус обычным текстом в середине | главное («есть обновление», «игра уже запущена») не отличается от второстепенного |
| тема Fluent по умолчанию, окно 760×620 | не похоже на игру; при открытии из игры выглядит как системная утилита |

Функции при этом все нужные — меняется только раскладка и язык.

## 2. Принципы

1. **Одна главная кнопка.** Её надпись и цвет — это и есть статус: «Играть», «Обновить и играть»,
   «Обновляю… 42 %», «Игра запущена». Всё остальное вторично.
2. **Редкое — в настройки.** Проверка файлов, откат, канал, папка игры, журнал — на отдельной
   странице «Настройки». Для них не нужно место на главном экране.
3. **Язык игрока.** Никаких id релизов, SHA и путей на главном экране. Версия — одной строкой
   мелко («HD 1.3 · 23 сентября»). Технические подробности — в журнале, журнал — в настройках.
4. **Тишина, пока всё хорошо.** Окно не показывает зелёных «всё в порядке». Появляется только то,
   что требует действия: обновление, отчёт ждёт ответа, ошибка.
5. **Похоже на игру.** Тёмная тема, фон — картинка или тон игры, заголовок — шрифт из набора HD.
   До утверждения арта — нейтральная тёмная тема (EDITIONS.md), но уже с местом под фон.
6. **Не ломать NativeAOT.** Никаких новых библиотек. Шрифт — Roboto и Roboto Condensed в ресурсах (≤ 300 КБ),
   фон — один JPEG (≤ 400 КБ). Итог по размеру лаунчера — не больше +1 МБ.

## 3. Окно

- Размер по умолчанию **960×600**, минимум **800×520**, запоминается в `settings.json`.
- Раскладка: слева навигация-рейка (4 страницы и внизу ссылка «Сайт игры ↗»), справа содержимое страницы.
  Страницы, а не окна: **Главная, Отчёты, Поддержать, Настройки**. Отдельными окнами остаются
  только форма отчёта F8 (её открывает игра) и подтверждения.
- Тема — **палитра геоскейпа X-Piratez**, снятая замером с кадра игры (дамп hdtest010:
  окно «О чём хотите знать?», боковая панель, космос за глобусом):

  | Роль | Цвет | Откуда в игре |
  |---|---|---|
  | фон | `#100010` | космос за глобусом |
  | рейка | `#080008` | правая панель геоскейпа |
  | заливка окон и карточек | `#0A1404` | кнопки «ЕСТЬ!», «По умолчанию» |
  | рамка окна | `#081000` снаружи + `#507818` внутри | двойная рамка окна |
  | акцент, главная кнопка, заголовки | `#80D000` | заголовок окна, кислотный лайм |
  | списки, успех | `#00C8B8` | строки списка в окне |
  | основной текст | `#D4ECDA` | светлее бирюзы — для абзацев |
  | вторичный текст | `#8E8AB0` | лавандовый текст Хабаропедии |
  | внимание, откат | `#782878` рамка, `#F080E0` текст | маджента часов и скоростей |
  | арт карточки | дуотон `#181868` / `#185888` / `#180810` | картинка в окнах геоскейпа |

  Углы почти прямые (2–3 px), как у окон игры. Все пары текст/фон — контраст не ниже 4.5:1.
- Шрифты: Roboto — тот же, что у HD-интерфейса игры (`hd/UI/*.ttf`), заголовки и главная
  кнопка — Roboto Condensed. Размеры: заголовок страницы 28, главная кнопка 22, текст 14, мелкий 12.
- Фон карточки игры — свой арт, сгенерированный в духе обложек Пираток и обработанный
  тем же дуотоном индиго, что и арт в окнах игры.
- Язык: ru и en, как сейчас (`Strings/*.json`); переключатель — в настройках.

## 4. Экраны

### 4.1 Главная

Слева направо: рейка, большая карточка игры, колонка «Что нового».

- **Карточка игры** (фон — арт игры или тёмный градиент до утверждения арта):
  - название «X-PIRATEZ HD» и строка версии: «HD 1.3 · обновлено 23 сентября»;
  - **главная кнопка** (см. таблицу 5) — во всю ширину карточки, высота 64;
  - под ней одна строка пояснения к состоянию, если оно нужно
    («Скачать 312 МБ», «Закройте игру, чтобы обновить»);
  - во время загрузки: полоса прогресса, «312 из 740 МБ · 18 МБ/с · осталось ~25 с», кнопка «Отмена».
- **Что нового**: changelog доступного (или установленного) релиза на языке лаунчера,
  прокрутка, без Expander. Пусто — колонка не показывается.
- **Плашки внимания** над карточкой, по одной, только когда есть повод:
  - «Команда ответила на отчёт XP-1042 — нужны подробности» → открывает Отчёты;
  - «Вышла новая версия лаунчера 1.4» → «Обновить лаунчер»;
  - «2 отчёта ждут отправки» → «Отправить».

### 4.2 Отчёты

То же, что окно «Отчёты» сейчас, но страницей:
- список карточек: номер, заголовок, дата, **стадия цветной меткой** (получен / разобран /
  в работе / **нужны подробности** — акцентом / исправлено / закрыт / дубликат / отклонён);
- у отправленного — последний ответ команды (две строки, дальше «…») и «Открыть на сайте»;
- у неотправленного — причина и «Отправить» / «Открыть форму» / «Удалить»;
- наверху: «Отправить очередь (N)» — только если очередь не пуста; строка «Проверено в 14:12».
- Счётчик на рейке: число отчётов, где нужны подробности, плюс неотправленные.

### 4.3 Поддержать

Две большие карточки-кнопки одна под другой (как в SupportWindow сейчас):
«Поддержать Dioxine — автора X-Piratez» и «Поддержать разработчиков HD», под каждой одна строка
пояснения. Без адреса — кнопка неактивна, «ссылка появится позже». Адреса — `defaults.json`.

### 4.4 Настройки

Группы, сверху вниз:
- **Игра:** папка игры (путь + «Изменить…»), язык лаунчера.
- **Обновления:** «Проверить обновления»; версия лаунчера и «Обновить лаунчер», если есть.
  Переключателя канала нет (решение 3 в §8).
- **Если что-то сломалось:** «Проверить и восстановить файлы» (с пояснением: пересчитывает все
  файлы, несколько минут), «Откатить последнее обновление» (с подтверждением).
- **Журнал:** последние 200 строк моноширинным, «Открыть папку журналов», «Скопировать».

### 4.5 Первый запуск

Папка игры не выбрана или не похожа на игру:
- на месте карточки игры — «Где установлена игра?», кнопка «Выбрать папку…» и строка
  «Это папка, где лежат openxcom_hd.exe, common и user».
- Этап 2 (EDITIONS.md): здесь же карточки комплектов (Оригинал / HD / HD 18+ / Классика) —
  в этом ТЗ только место под них.

### 4.6 Лаунчер открыт из игры

Кнопка «Лаунчер» в главном меню игры открывает то же окно, но игра уже запущена:
- главная кнопка — «Игра запущена» (неактивна, серая), обновления не ставятся
  (так и сейчас: `UpdateBlockedException`);
- если есть обновление — строка «Обновление установится после выхода из игры».
- Отчёты, Поддержать и Настройки работают как обычно.

### 4.7 Отчёт из игры (F8)

Отдельное окно 960×640 поверх игры на паузе (`--report`), в той же палитре, без рейки.
- Шапка: «Сообщить о проблеме» и строка «Игра на паузе — закройте окно, и она продолжится».
- Слева (380 px): **снимок экрана крупно** — это главное, что видит команда; под ним рамка
  «Что приложить»: снимок, журнал, сохранение (выбор: «эта игра, как она есть сейчас» или файл),
  пояснение про вычистку журнала; «Технические данные» свёрнуты.
- Справа: «Что это» — кнопками-чипами в одну строку, а не выпадающим списком (Баг выбран сразу);
  «Коротко, в одну строку»; «Что случилось»; «Как повторить» — необязательное;
  «Что ожидали» и «Что получилось» — рядом, маленькие.
- Низ: строка статуса (не заполнено / отправляю / сайт недоступен — в очереди), «Отмена»,
  «Сохранить черновик», главная «Отправить» (в очереди — «Повторить отправку»).
- После отправки — рамка «Отчёт отправлен XP-1043», что не приложилось и почему,
  «Открыть отчёт на сайте» и «Вернуться в игру».

## 5. Главная кнопка: состояния

| Состояние | Надпись | Вид | Строка под кнопкой |
|---|---|---|---|
| папка не выбрана | Выбрать папку игры | акцент | Где лежат openxcom_hd.exe, common и user |
| проверка при запуске | Играть | акцент, активна | Проверяю обновления… (мелко, не мешает играть) |
| всё свежее | Играть | акцент | — |
| есть обновление | Обновить и играть | акцент | HD 1.4 · скачать 312 МБ · [Играть без обновления] |
| загрузка / установка | Обновляю… 42 % | тёмная кнопка, прогресс полосой внизу (текст поверх заливки не читается) | 312 из 740 МБ · 18 МБ/с · [Отмена] |
| игра запущена | Игра запущена | серая, неактивна | (если есть обновление) установится после выхода |
| нужен новый лаунчер (minLauncher) | Обновить лаунчер | акцент | Эта версия игры требует лаунчер 1.4 |
| нет сети | Играть | акцент | Не удалось проверить обновления · [Повторить] |
| ошибка установки | Повторить | тревога | текст ошибки одной строкой · [Подробнее] → журнал |
| проверка файлов (запущена из настроек) | Проверяю файлы… 67 % | серая, прогресс полосой внизу | — |

«Играть без обновления» — ссылка, а не кнопка: обновление остаётся рекомендуемым путём.

## 6. Что не входит

- Карточки комплектов, галочки компонентов и моды — этап 2 (EDITIONS.md), здесь только место.
- Новости с сайта — источника нет (changelog есть только в manifest релиза).
- Вход в учётную запись сайта — лаунчер работает через секретные ссылки тикетов.
- Изменение механики обновлений, самообновления, отчётов.

## 7. Приёмка

- Все функции прежнего окна доступны: ни одна кнопка не пропала, только переехала.
- От запуска до «Играть» — один клик, если обновлений нет.
- Главный экран не содержит id релиза, SHA, путей и журнала.
- Окно 800×520 — ничего не обрезано; ru и en — ни одна надпись не выходит за кнопку.
- Размер `XPiratezLauncher.exe` вырос не больше чем на 1 МБ (сейчас 22,2 МБ).
- Открытый из игры лаунчер не даёт запустить вторую копию игры.
- Headless-режимы и `--report` / `--refresh` работают как раньше (тесты зелёные).

## 8. Решения Vitali (2026-09-23)

1. Окно **960×600** — годится.
2. Фон карточки игры — **свой арт в духе Пираток, сгенерированный** (не готовая картинка мода).
   До него — тёмный градиент с местом под фон.
3. Тестовые сборки **пока не выкладываем**: в `defaults.json` остался один канал `stable`,
   переключателя канала в интерфейсе нет. Для отладки — `--channel` в командной строке.
4. «Поддержать»: разработчики HD — https://www.donationalerts.ru/r/pepelatzigravetzappa
   (по https, иначе кнопка неактивна); Dioxine — адреса пока нет, кнопка неактивна,
   «ссылка появится позже».
5. «Что нового» — **только changelog релиза**, новостей с сайта нет.
6. **Ссылка на сайт обязательна**: пункт «Сайт игры ↗» внизу рейки, открывает `portalUrl`
   из `defaults.json` в браузере.
