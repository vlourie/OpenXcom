# Портал, лаунчер и обратная связь — риски

Версия 0.1 · 2026-09-22.

| № | Риск | Чем грозит | Что делаем |
|---|---|---|---|
| R-P01 | Нет разрешения Dioxine и прав на данные UFO | лаунчер и страница донатов не могут выйти публично | OPEN_QUESTIONS, вопрос 1; по умолчанию распространяем только своё |
| R-P02 | Трафик: 1,9 ГБ первой установки на игрока | счёт за CDN, медленная первая установка | хранилище без платы за исходящий трафик; хранение по содержимому снимает повторы между паками (R-049); дельта следующих релизов — только новые блобы |
| R-P03 | «Небольшой» лаунчер на .NET | self-contained WinForms — 70+ МБ; NativeAOT с WinForms не поддерживается | замер прототипа Avalonia/NativeAOT против WinForms в начале этапа 1 |
| R-P04 | Полноэкранный SDL 1.2 и внешнее окно формы | окно под игрой, игра не разворачивается после формы | проверка в матрице этапа 3; запасной путь — движок сам сворачивает окно перед запуском формы и разворачивает после |
| R-P05 | Две копии мода (репозиторий и установка, R-015) | в релиз уедет не та копия | ReleaseBuilder берёт только `dist/_stage` после проверок `build.ps1`, сам копии не выбирает |
| R-P06 | Утечка ключа подписи | подделанный релиз у всех игроков | ключ вне репозитория и вне лаунчера; в лаунчере два открытых ключа для ротации; отзыв релиза в админке |
| R-P07 | Игрок правил управляемые файлы (свои паки в `hd`) | обновление сотрёт его работу | «изменён игроком» показывается до установки, по умолчанию не заменяется; резервная копия |
| R-P08 | Сейвы и логи — личные данные | утечка при отправке или хранении | только с галочкой, вычистка до отправки, подписанные ссылки на 5 минут, срок хранения |
| R-P09 | Объём ТЗ против одного разработчика | сайт на полпути, лаунчер без поддержки | этап 1 сам по себе полезен и работает без сервера; каждый этап закрывается рабочим результатом |
| R-P10 | Правка движка расходится с апстримом | конфликты при слиянии MeridianOXC | вся логика в новом `Feedback.*`, в чужих файлах — вызовы в одну строку |
| R-P11 | Антивирусы ругаются на неподписанный лаунчер и bootstrapper | игроки боятся ставить | подпись кода (Authenticode) — отдельный организационный вопрос; до неё — хэши на сайте |
| R-P12 | Порог .NET 8 → 10 | ТЗ рекомендует .NET 8, его поддержка кончается 2026-11-10 | берём .NET 10 LTS (до ноября 2028) |
