Версия 0.1 · 2026-09-22. Сначала блокирующие, потом то, для чего взято значение по умолчанию.

## Решённые 2026-09-22

- **Домен (2026-09-23).** `x-piratez.mywire.org` на Dynu, внешний IP сервера динамический. Запись обновляет контейнер `portal/deploy` (ddns). Ещё открыто: проброс портов 80/443 на роутере и сертификат Let's Encrypt.

1. **Права.** Разрешение Dioxine получено до начала работ: HD-пак поверх его графики, его имя,
   ссылки и страница доната публикуются. Данные UFO/TFTD по-прежнему не наши. Набор того, чем
   управляет лаунчер, задаётся в manifest (`roots`), поэтому включить туда сам мод Piratez позже —
   правка релиза, а не кода. На этапе 1 roots — только наши файлы.
2. **F8.** Отчёт игрока — F8, дамп HD-кадров — Ctrl+F8. Переносится на этапе 3 вместе с
   `CLAUDE.md` и `tools/hdtest_README.md`.
3. **Хостинг.** Разработка и тесты — на этой машине (здесь нет Docker: этап 1 обходится без
   сервера, для этапа 2 Postgres поднимается локально). Потом портал переезжает на свой сервер
   с Docker в локальной сети. Внешний домен и CDN — открытый вопрос к моменту публикации.
4. **Код.** Готового кода нет, всё пишется с нуля в `portal/` этого репозитория.

## Открытые

- **Нужно для запуска сайта (этап 2 готов, ждёт значений).** Всё задаётся в `portal/deploy/portal.env`
  и на странице «Управление → Telegram», код не меняется:
  - Telegram: токен бота, chat ID чата команды и, если нужно, отдельные чаты или темы для
    художников и программистов;
  - SMTP: сервер, порт, логин, адрес отправителя — без него не работают подтверждение
    регистрации и сброс пароля (гостевые тикеты работают);
  - проброс портов 80 и 443 на роутере на сервер — без него нет сертификата и сайта снаружи;
  - адрес кнопки «Скачать лаунчер» и адрес репозитория релизов для блока «текущая версия».
- CDN — к публикации наружу (этап 6).
- Официальные URL донатов Dioxine и команды — к этапу 5.
- Подпись кода Authenticode для лаунчера — риск R-P11.

## Со значением по умолчанию (в конфигурации, меняется без кода)

| Что | По умолчанию |
|---|---|
| Домен и API URL | `https://x-piratez.mywire.org`; в разработке `http://localhost:5080` |
| Каталог игры | выбирает игрок; признак — `OpenXComEx.exe`/`openxcom_hd.exe` + `common` + `user` |
| Имя exe в релизе | `openxcom_hd.exe` (как в `build_config.json`) |
| Вложения | PNG/JPG/WebP, `.log`/`.txt`, `.sav`/`.asav`, `.zip`; тип проверяется по содержимому. Логи, сейвы и архивы — только с галочкой согласия |
| Размер | до 50 МБ на файл, ZIP до 100 МБ (не распаковывается), до 10 файлов и 200 МБ на тикет. Раздельные лимиты по типу и проверка размеров картинки в пикселях отложены |
| Хранение | вложения и дампы — 180 дней после закрытия тикета (чистка ещё не написана — этап 6), логи лаунчера — 10 файлов по 5 МБ |
| Языки | ru основной, en второй |
| Каналы | `stable` по умолчанию, `test` |
| Telegram | без токена уведомления копятся в очереди и уходят, как только токен задан; без маршрута — не создаются |
| Донаты | карточки скрыты, пока не заданы URL; разрешение Dioxine есть |
| Антивирус | ClamAV в контейнере (compose); пока он не ответил, файл «проверяется» и не отдаётся. Без настроенного ClamAV (разработка) файл помечается «без проверки» и доступен команде — см. DECISIONS |
| Название и логотип | «X-Piratez HD» — рабочее, без логотипа |
