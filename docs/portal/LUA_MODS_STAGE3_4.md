## Как устроен каталог

- `Выпуск/lua_catalog/`: папки `cm-<id>`, `catalog.json` с sha256 каждого файла, `revoked.json` для манифеста. Управляет `tools/lua_catalog.py`.
- `release.ps1`: есть `catalog.json` → `sync` в стейдж, `--revoked` в сборщик. Есть моды, а `MinLauncher` выпуска ниже `minLauncher` каталога → стоп:
  старый лаунчер поставил бы мод любому и не включил бы Lua.
- Компонент не новый вид, а `shared` с отметкой `catalog`: не отмечается по умолчанию и не предлагается как новинка.
- Отзыв повторяется в каждом следующем выпуске: игрок, пропустивший выпуск, всё равно его получит.
- Файлы мода после отзыва снимает лаунчер по `InstalledRoots`, а не по `Deletes` манифеста. Предупреждение сборщика `left behind: its root is no longer managed` здесь не значит, что файлы останутся.

## Что отличается от ТЗ и что ограничено

- Звук только WAV; OGG, PCK, MAP в V1 не разрешены.
- Опция Lua одна на игру: при активном моде каталога заработают и активные локальные моды этой сборки.
- Отзыв выключает мод по id во всех сборках. Своя папка автора остаётся, автор может включить её снова.
- Файл заявки отдаётся только после антивируса: первый `pull` может прийти без архива, следующий докачает, `check` без архива останавливается, не меняя статус.
