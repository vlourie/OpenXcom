# Грабли

Отрицательное знание проекта: что уже пробовали и почему это не работает.
Перечитыванием исходников не восстанавливается — только отсюда.

Файл импортируется в `CLAUDE.md` и попадает в контекст **до** первого действия.
Держи его коротким: больше ~150 строк — значит пора обезвреживать старые грабли тестами и удалять.

## Протокол

| Наступил раз | Что обязан сделать |
|---|---|
| 1 | запись здесь: `python tools/rake.py add` |
| 2 | **тест или хук** — текст не сработал, нужна автоматика |
| 3 | правка архитектуры, чтобы ошибиться было нельзя |

Наступил снова — `python tools/rake.py hit R-00N`. Счётчик врать не должен: он единственная честная метрика того, работает система или нет.

Обезвредил (написал тест, который ловит эту ошибку) — ставь `Статус: обезврежены` и оставляй запись. Удалять можно, когда защита продержалась пару месяцев.

## Формат

Разделы ниже парсятся скриптами, поля менять нельзя.

```
## R-000  Короткий заголовок в одну строку
Статус:   активны
Файлы:    src/Foo/*.cpp, rulesets/*.rul
Симптом:  что видно снаружи
Причина:  что происходит на самом деле
Правило:  что делать вместо этого
Защита:   tests/test_foo.py   (или: нет)
Наступал: 1   Последний: 2026-01-01
```

`Файлы:` — глобы через запятую. По ним хук находит грабли перед правкой файла.

## R-001  PowerShell-скрипт с кириллицей без BOM не запускается
Статус:   обезврежены
Файлы:    *.ps1, *.psm1, *.psd1, tools/*.ps1, .claude/hooks/*.ps1
Симптом:  ParserError при запуске: "Missing '=' operator after key in hash literal", "The hash literal was incomplete"; в тексте ошибки вместо кириллицы мусор вида Ð¿Ð°ÐºÐµÑ‚
Причина:  Windows PowerShell 5.1 читает файл без BOM как ANSI (cp1251). Файл записан в UTF-8, каждая русская буква распадается на два байта, рвутся кавычки и скобки — скрипт не разбирается
Правило:  все .ps1/.psm1/.psd1 сохранять в UTF-8 СО спецификацией (BOM), переводы строк CRLF. Проверка: tools\fix_bom.ps1, починка: tools\fix_bom.ps1 -Fix
Защита:   .claude/hooks/bom-guard.ps1 (PostToolUse) дописывает BOM после каждой записи в .ps1
Наступал: 3   Последний: 2026-09-18
